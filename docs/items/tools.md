## 通用装备规则

主动用品需要先移入物品栏并选中；被动用品携带在背包或物品栏即生效；手持装备只有选中时生效。每个条目采用相同的五项说明。同一属性只取最强一件，不叠加；不同属性可共存。选中加速装备时不能同时手持武器。

医疗补给的体温上限为36°C，饥饿补至10时保留已有超额值；它们不是食品，不受饥饿大于10的禁食限制。倒地可用主动治疗及回城用品。取消未完成长按不消耗，完成时即使已满状态也会消耗；成功反馈使用预渲染医疗或传送动画。所有次数随物品转移和存档保存，耗尽消失，不因重新放置或登录补满。

救援只针对其他在线倒地玩家，须在规定距离内、瞄准正确且视线畅通。回城寻找距原点最近的可站立格中心，木地板可落脚；同距格中选择到最近怪物格距离最大者，仍并列按坐标稳定选择，不受沿途障碍限制。回城不恢复体温或饥饿。

## 自身恢复与补给

### 急救包

![急救包](../../cold_world_game/static/assets/first_aid_kit.png)

- **名称与标识**：急救包 / First aid kit / `first_aid_kit`。
- **获取方式**：每个自然房屋箱子独立 2% 概率生成1件；也可在[自动医疗柜](../building/machines.md#自动医疗柜)兑换，完整价格见设施条目。
- **效果与数值**：体温恢复至36°C，饥饿恢复到至少10；医疗光圈与红色十字绽放。
- **操作方式**：选中后长按0.5秒，无需篝火；手机长按“使用”。
- **消耗与限制**：一次性；恢复与消耗原子提交。

### 暖宝宝贴

![暖宝宝贴](../../cold_world_game/static/assets/heat_patch.png)

- **名称与标识**：暖宝宝贴 / Heat patch / `heat_patch`。
- **获取方式**：每个自然房屋箱子独立 2% 概率生成1件；也可在[自动医疗柜](../building/machines.md#自动医疗柜)兑换，完整价格见设施条目。
- **效果与数值**：体温直接恢复至36°C，饥饿保持不变；播放小型医疗光圈。
- **操作方式**：选中后长按0.5秒，无需篝火；手机长按“使用”。
- **消耗与限制**：一次性；饥饿为0或超过10时也可用。

### 口袋暖炉

![口袋暖炉](../../cold_world_game/static/assets/pocket_stove.png)

- **消耗与限制**：初始3次，用尽消失。

![复苏针](../../cold_world_game/static/assets/revival_syringe.png)

- **消耗与限制**：一次性，完成后消失。

## 导航工具

### 指南针

![指南针](../../cold_world_game/static/assets/compass.png)

- **名称与标识**：指南针 / Compass / `compass`。
- **获取方式**：每个自然房屋箱子独立 2% 概率生成1件。
- **效果与数值**：红色针尖指向距自己欧氏距离最近的合格建筑区块中心，而不是固定指北；蓝色针尖指向相反方向。寻找目标时应跟随红色针尖，不要跟随蓝色针尖。整个区块须与当前游戏画面无交集（边界接触也排除）；从玩家指向目标的方向与从原点指向玩家的方向点积≥0，垂直方向也合格。在原点时不限制方向，同距目标按区块横坐标、纵坐标稳定选择。
- **操作方式**：放在背包或物品栏即可自动指向，不用选中、点击或长按；桌面与手机均适用。红色针尖朝向与游戏画面的上下左右一致，不是现实手机朝向。
- **消耗与限制**：不是建筑，不能放置；不消耗。区块按自然类型识别，拆过房屋仍算建筑区块，玩家在森林盖房不会改变类型。浏览器独立Worker只查询区块类型，不探索服务器地图，不生成箱子内容；所有随身指南针共用结果。搜索或连接不可用时指针变暗，不把尚未完成的搜索当成有效目标。

## 随身被动装备

![警长徽章](../../cold_world_game/static/assets/sheriff_badge.png)

- **名称与标识**：警长徽章 / Sheriff badge / `sheriff_badge`。
- **获取方式**：每个自然房屋箱子独立 2% 概率生成1件。
- **效果与数值**：任何武器对小怪、快速怪的伤害×2，包括命中时的子弹、爆炸与每次灼烧；不增加击退，不增强对大怪或玩家的伤害。
