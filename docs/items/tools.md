## 通用装备规则

主动用品需要先移入物品栏并选中；被动用品携带在背包或物品栏即生效；手持装备只有选中时生效。每个条目采用相同的五项说明。同一属性只取最强一件，不叠加；不同属性可共存。选中加速装备时不能同时手持武器。

医疗补给的体温上限为 36°C，饱食度上限为 10。满饱食时仍可用医疗补给。倒地可用主动治疗及回城用品。取消未完成长按不消耗，完成时即使已满状态也会消耗；成功反馈使用预渲染医疗或传送动画。所有次数随物品转移和存档保存，耗尽消失，不因重新放置或登录补满。

救援只针对其他在线倒地玩家，须在规定距离内、瞄准正确且视线畅通。回城寻找距原点最近的可站立格中心，木地板可落脚；同距格中选择到最近怪物格距离最大者，仍并列按坐标稳定选择，不受沿途障碍限制。回城不恢复体温或饥饿。

## 自身恢复与补给

### 急救包

![急救包](../../cold_world_game/static/assets/first_aid_kit.png)

- **名称与标识**：急救包 / First aid kit / `first_aid_kit`。
- **获取方式**：每口普通自然箱有 3.9% 概率出现（1 件）；也可在[自动医疗柜](../building/machines.md#自动医疗柜)兑换，完整价格见设施条目。
- **效果与数值**：体温恢复至36°C，饱食度恢复到 10；医疗光圈与红色十字绽放。
- **操作方式**：选中后长按0.5秒，无需篝火；手机长按“使用”。
- **消耗与限制**：一次性；恢复与消耗原子提交。

### 暖宝宝贴

![暖宝宝贴](../../cold_world_game/static/assets/heat_patch.png)

- **名称与标识**：暖宝宝贴 / Heat patch / `heat_patch`。
- **获取方式**：每口普通自然箱有 2.9% 概率出现（1 件）；也可在[自动医疗柜](../building/machines.md#自动医疗柜)兑换，完整价格见设施条目。
- **效果与数值**：体温直接恢复至36°C，饥饿保持不变；播放小型医疗光圈。
- **操作方式**：选中后长按0.5秒，无需篝火；手机长按“使用”。
- **消耗与限制**：一次性；饱食度为 0 或 10 时也可用。

### 口袋暖炉

![口袋暖炉](../../cold_world_game/static/assets/pocket_stove.png)

- **名称与标识**：口袋暖炉 / Pocket warmer / `pocket_stove`。
- **获取方式**：每口普通自然箱有 4.5% 概率出现（1 件）。
- **效果与数值**：每次恢复12°C体温，上限36°C；不改变饥饿，初始3次。
- **操作方式**：选中后长按0.5秒；手机按住使用，无需篝火，倒地也能用。耗尽消失。
- **消耗与限制**：初始3次，用尽消失。

### 葡萄糖补给

![葡萄糖补给](../../cold_world_game/static/assets/glucose_vial.png)

- **名称与标识**：葡萄糖补给 / Glucose vial / `glucose_vial`。
- **获取方式**：也可在[自动医疗柜](../building/machines.md#自动医疗柜)兑换，完整价格见设施条目。

- **操作方式**：选中后长按0.5秒，无需火，倒地也能用；它是恢复用品，不是可超额进食的食品。
- **消耗与限制**：一次性，完成后消失。

### 野外补给袋

![野外补给袋](../../cold_world_game/static/assets/field_supply.png)

- **名称与标识**：野外补给袋 / Field supply pouch / `field_supply`。

- **操作方式**：选中长按1秒，无需火，倒地可用；手机按住使用，耗尽消失。

### 燃料补给包

![燃料补给包](../../cold_world_game/static/assets/fuel_pack.png)

- **名称与标识**：燃料补给包 / Fuel supply pack / `fuel_pack`。

- **操作方式**：选中长按1秒，无需火；每次消耗1包，背包和物品栏全满也可拆包。手机按住使用。
- **消耗与限制**：一次性，完成后消失。包含原物品格在内必须能装下全部5木材，空间不足或结算失败时不拆包、不扣物品。

## 队友救援

### 除颤器

![除颤器](../../cold_world_game/static/assets/defibrillator.png)

- **名称与标识**：除颤器 / Defibrillator / `defibrillator`。
- **获取方式**：每口普通自然箱有 2% 概率出现（1 件）；也可在[队友救援补给机](../building/machines.md#队友救援补给机)兑换，完整价格见设施条目。

## 点火工具

### 打火机

![打火机](../../cold_world_game/static/assets/lighter.png)

- **名称与标识**：打火机 / Lighter / `lighter`。
- **获取方式**：每口普通自然箱有 4% 概率出现（1 件）；新玩家初始携带1件。
- **效果与数值**：初始可点火 20 次，不代替木材燃料。
- **操作方式**：打开篝火，放入火种格并添加木材，点击“点燃”；不能手持直接点火。
- **消耗与限制**：每次成功点燃扣1次，用尽消失；木材另行消耗。成功点燃后，尚有次数且30格背包有空位时自动收回背包原物品；背包满则留在篝火，不转入物品栏、不丢到地面。

## 导航工具

### 指南针

![指南针](../../cold_world_game/static/assets/compass.png)

- **名称与标识**：指南针 / Compass / `compass`。
- **获取方式**：每口普通自然箱有 2% 概率出现（1 件）。
- **效果与数值**：红色针尖指向距自己欧氏距离最近的合格建筑区块中心，而不是固定指北；蓝色针尖指向相反方向。寻找目标时应跟随红色针尖，不要跟随蓝色针尖。整个区块须与当前游戏画面无交集（边界接触也排除）；从玩家指向目标的方向与从原点指向玩家的方向点积≥0，垂直方向也合格。在原点时不限制方向，同距目标按区块横坐标、纵坐标稳定选择。
- **操作方式**：放在背包或物品栏即可自动指向，不用选中、点击或长按；桌面与手机均适用。红色针尖朝向与游戏画面的上下左右一致，不是现实手机朝向。
- **消耗与限制**：不是建筑，不能放置；不消耗。区块按自然类型识别，拆过房屋仍算建筑区块，玩家在森林盖房不会改变类型。浏览器独立Worker只查询区块类型，不探索服务器地图，不生成箱子内容；所有随身指南针共用结果。搜索或连接不可用时指针变暗，不把尚未完成的搜索当成有效目标。
