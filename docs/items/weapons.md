# 武器图鉴与使用

[返回项目首页](../../README.md) · [手册目录](../README.md) · [本组目录](README.md)

自然空地中的固定机枪不是可携带物品，其5000发弹药、占座、安全距离与操作见[户外座位与固定武器](../building/outdoor-facilities.md#固定机枪)；地雷为可放置建筑，见[建造手册](../building/building.md#地雷)。

## 通用攻击规则

所有武器按攻击方式归类，条目统一介绍名称与标识、获取方式、效果与数值、操作方式、消耗与限制。必须放入物品栏并选中；倒地不能攻击。伤害作用于怪物血量，玩家没有独立血条。怪物属性与作息见[怪物手册](../world/combat.md)，伤害加成见[警长徽章](tools.md#警长徽章)。

有效攻击受各自冷却限制，每个模拟tick最多发射一次，不补发卡顿期间错过的攻击。除电锯外，有限近战每次有效挥动（含空挥）扣1次；电锯只在一次攻击命中至少一只怪物或完成一次方块拆除时扣1次，空挥及取消采集不扣次，冷却内点击不扣次数；枪械每次射击扣1发，散弹多个弹丸仍只扣1发。最后一次用完后物品消失，已发射投射物仍结算；不能装填或用转移补满次数。

## 弹道、范围与状态

普通玩家子弹从射手坐标发出，不能命中自己，可贯穿多只怪物及其他玩家；每枚弹丸对同一实体至多伤害一次，不衰减。墙和柱子可穿透，树木阻挡；箱子、篝火、存钱罐和所有机器仅阻挡怪物子弹，不阻挡玩家子弹。一次射击对同一玩家最多扣1体温和1饥饿，玩家体温≤0时不再受子弹伤害。

普通子弹在距离射手当前坐标超过当前视野半对角线时消失：`sqrt(视野宽²+视野高²)/2`；32×18格视野约18.36格，手机随实际画布更新，转屏也更新已发射子弹的上限。不是累计路程；射手离线使用最后位置和视野，全员离线暂停。部分枪械收到按下边沿立即产生首发，无须等下一tick；普通子弹仍按实际弹速飞行，在碰撞时结算伤害。

近战以瞄准向量为中线，用物品所列半径和扇形角度群攻，攻击视线须畅通。180°即向前半圆，边缘包含在内；不伤玩家。单击立即播放对应八方向PNG刃光与挥动音效，伤害由服务器确认；长按采集不等于连续攻击。

冰冻使速度×0.5，大怪期间不能发射远程子弹；活动怪物使用蓝色差分，白天倒地怪物仍受伤但不切换冰冻立绘。灼烧每0.5秒跳一次4点基础伤害、不击退，状态结束停止；同状态刷新持续时间、不叠层，冰冻与灼烧可同时存在。休眠倒地怪物不被击退；活动怪物受到直接近战/普通弹击退，快速怪为普通怪的2.5倍，大怪为0.6倍；爆炸与灼烧无击退。

爆炸仅伤怪物，包含白天休眠怪物，不伤玩家和建筑；按爆心欧氏距离结算且不受障碍遮挡。手机投掷可长按场景落点，或瞄准后按住“使用”。

## 枪械与追踪武器

### 手枪

![手枪](../../cold_world_game/static/assets/handgun.png)

- **名称与标识**：手枪 / Handgun / `handgun`。
- **获取方式**：自然箱子枪械组抽选，折合每箱 14% 概率；新玩家初始携带1件；也可在[自动枪械机](../building/machines.md#自动枪械机)兑换，完整价格见设施条目。
- **效果与数值**：每弹基础伤害5，最短间隔0.25秒，弹速20格/秒。
- **操作方式**：选中后单击左键；手机瞄准后点“使用”。
- **消耗与限制**：初始100发，每枪1发，用完消失，不能装填。

## 近战武器

### 斧头

![斧头](../../cold_world_game/static/assets/axe.png)

- **名称与标识**：斧头 / Axe / `axe`。
- **获取方式**：新玩家初始携带。
- **效果与数值**：半径3格、180°扇形群攻，直接伤害4，最短间隔0.5秒。
- **操作方式**：选中后单击左键朝瞄准方向挥动；手机点“使用”，无需长按。采树或拆建筑另用长按，容器/机器须用窗口内拆除按钮。
- **消耗与限制**：无次数限制；攻击仍受冷却、距离、方向和视线限制。不能用Q、拖到场景或手机丢弃，可正常转移背包或存入箱子。

### 电锯

![电锯](../../cold_world_game/static/assets/chainsaw.png)

- **名称与标识**：电锯 / Chainsaw / `chainsaw`。
- **获取方式**：每个自然房屋箱子独立 2% 概率生成1件。
- **效果与数值**：半径2.5格、180°扇形群攻，直接伤害6，最短间隔0.5秒。伐木只需0.25秒；其余拆除速度与斧头相同。
- **操作方式**：选中后单击左键朝瞄准方向挥动；手机点“使用”，无需长按。伐木和拆方块需长按；容器取空后在窗口长按拆除。
- **消耗与限制**：初始200次，一次群攻命中至少一只怪物才扣1次，与命中数量无关；每成功拆除一个方块扣1次。空挥、无效操作和中途取消采集不扣次，用尽消失；不能补充次数。伤害、采集掉落和扣次一起原子保存，失败全部回退。
