# 采集、制作与建造

[返回项目首页](../../README.md) · [手册目录](../README.md) · [本组目录](README.md)

本册说明材料、基础建筑和共用操作。所有容器与机器的功能、容量、价格及生成概率统一见[设施手册](machines.md)；物品丢弃与拾取见[背包手册](../guide/inventory.md#丢弃与拾取)。

## 材料与基础建筑

### 木材

![木材](../../cold_world_game/static/assets/wood.png)

- **名称与标识**：木材 / Wood / `wood`。
- **获取方式**：密林外砍树每棵随机获得1～3个；自然箱50%概率生成1～5个；拆木墙/地板、回收栅栏及机器兑换也可获得。密林树木可砍来开路。
- **效果与数值**：基础制作原料和篝火燃料，每件独占1格。
- **操作方式**：按B在合成面板制作，或存入篝火燃料槽；普通木材不是可直接放置的方块。
- **消耗与限制**：按配方或燃烧消耗；不能通过循环制作、拆除或回收增殖。

### 木栅栏

![木栅栏](../../cold_world_game/static/assets/fence.png)

- **名称与标识**：木栅栏 / Wooden fence / `fence`。
- **获取方式**：1木材制作2个，或拆下已有栅栏。
- **效果与数值**：阻挡移动，不挡视线和双方子弹。
- **操作方式**：选中后左键放置；斧头在3格内对准长按0.5秒拆除。
- **消耗与限制**：放置消耗1件，玩家拆除掉1个栅栏而非木材；2栅栏可回收1木材。大怪拆除不掉物资。

### 木墙

![木墙](../../cold_world_game/static/assets/wall.png)

- **名称与标识**：木墙 / Wooden wall / `wall`。
- **获取方式**：1木材制作1个、自然房屋墙柱，或建材机器兑换。
- **效果与数值**：阻挡移动、视线和子弹，并可围成封闭房间。木柱采用相同规则。固定机枪连续命中 24 发可摧毁木墙。
- **操作方式**：选中后左键放置；斧头在3格内对准长按1.5秒拆除。
- **消耗与限制**：放置消耗1件，玩家拆除得1木材；无设施八邻域间距限制。大怪拆除不掉物资。

### 木门

![木门](../../cold_world_game/static/assets/door.png)

用 **2 木材**制作，放进墙上的一格开口。初始关闭。两格内点击木门可开关，手机可点门或瞄准后点「使用」。门关闭时挡移动、视线和热量，和木墙一样参与房间封闭判定。打开后玩家和怪物可以通行，热量沿开口传播。门口有玩家或怪物时无法关上。子弹沿用木墙规则。

倒地时也可放置或开关木门。按住 Shift 用斧头或电锯长按 **1.5 秒**可拆回一扇木门，手机使用「拆除」。大怪可以拆闭门，需 **10 秒**。

### 木地板

![木地板](../../cold_world_game/static/assets/floor.png)

- **名称与标识**：木地板 / Wooden floor / `floor`。
- **获取方式**：1木材制作1个，或建材机器兑换。
- **效果与数值**：玩家与怪物可走，视线和子弹可穿过，也可传送落脚；地板格不刷怪。地板按整间[封闭房间的覆盖比例](../world/survival.md#环境温度与室内供暖)提供保温。
- **操作方式**：选中后左键放置；斧头在3格内对准长按0.5秒拆除。
- **消耗与限制**：放置消耗1件，拆除得1木材；地板占用建筑格。冰湖上的地板和桥面可以承托篝火。

### 地雷

![地雷](../../cold_world_game/static/assets/landmine.png)

- **名称与标识**：地雷 / Landmine / `landmine`。
- **获取方式**：普通自然箱有 2% 概率出现 1 个。
- **效果与数值**：铺在地面，玩家与怪物可走，不挡视线或子弹；怪物进入该格立即触发一次爆炸，欧氏距离≤3格的怪物受20点基础伤害，与手榴弹完全相同，使用相同爆炸PNG和音效。移动跨过整格也能触发，不只检查帧末位置。
- **操作方式**：选中后对3格内空位左键放置，手机使用放置按钮；不需要另外点火。玩家经过不引爆，也不受爆炸伤害。
- **消耗与限制**：每次放置消耗1个，爆炸后建筑消失，无重复爆炸、无方块破坏和玩家伤害；不可拆回或制作。地雷占一格，不能与地板/其他建筑叠放。放置者的伤害修正按手榴弹规则结算，怪物掉落照常；消耗、伤害、掉落与保存整次成功或整次回退。

## 制作配方

按B同时打开背包与合成，无需工作台或制作时间。共同检查背包和物品栏，优先从背包取料；产物优先放快捷物品栏，再放背包。扣料后必须装得下全部产物，否则整次失败。制作、产物和保存原子完成。

| 配方标识 | 完整投入 | 完整产物 |
| --- | --- | --- |
| `fence` | 1木材 | 2木栅栏 |
| `wall` | 1木材 | 1木墙 |
| `door` | 2木材 | 1木门 |
| `floor` | 1木材 | 1木地板 |
| `chest` | 2木材 | 1箱子 |
| `campfire` | 1木材 | 1熄灭的篝火 |
| `recycle_fences` | 2木栅栏 | 1木材 |

## 放置规则

建筑须在物品栏中选中；鼠标指向显示绿/红放置预览，左键单击放置1个，长按不连续放，右键不建造。手机点“放置”。服务器最终确认，成功才消耗物品。

- 落点须在玩家欧氏距离3格内、已生成、没有其他建筑或树木，不能堵塞必须保留的出生通路。木地板可以铺在玩家或怪物脚下。倒地时可放篝火、木墙、木地板和木门。
- 冰湖格必须先被冰冻术稳定，才可在该格铺地板；湖上的篝火需要地板或修好的桥面承托。
- **不检查放置视线**：中间有墙或其他方块不单独导致失败，距离、空位和其余条件仍有效。
- 箱子、篝火、存钱罐与所有机器彼此在八邻域内不能相邻，包括斜对角；木墙、栅栏和地板不受这一间距规则约束。
- 左键点击已有容器通常优先打开窗口；投射用品瞄准行为见[操作手册](../guide/controls.md)。

使用[建筑法杖](../items/tools.md#建筑法杖)或[地板法杖](../items/tools.md#地板法杖)时，瞄准 3 格内的中心。手持建筑法杖可在游戏场景上滚动滚轮切换横竖，手机点「旋转」。预览按格显示可铺位置，障碍、未生成区块和其他放置限制只影响对应的格子。每成功铺一格自动扣 1 木材。

## 采集与拆除

站立、选中斧头或[连锁电锯](../items/weapons.md#连锁电锯)，在3格内对同一树或基础建筑长按左键；斧头砍树0.5秒，电锯砍树0.25秒；其他方块两者相同：栅栏0.5秒，墙1.5秒，地板0.5秒。必须保持交互路径畅通。松开、换物品/目标、超距或倒地会清空进度。电锯只在完成一次方块拆除时扣1次，不按tick或掉落数量扣次；中途取消、无效目标和受阻不扣次，用尽后消失。电锯不能修复或通过转移重置次数。[连锁电锯](../items/weapons.md#连锁电锯)砍树时连砍半径 5 格内最多 4 棵树，允许跨空格。普通斧头需随身携带[伐木护符](../items/tools.md#伐木护符)，每次砍倒树有 35% 概率触发。

**箱子、篝火、存钱罐和所有机器统一走窗口拆除**：2格内打开窗口，取空物品/燃料/火种/余额，再选斧头或电锯长按窗口内拆除按钮1.5秒。场景点击、Shift点击或手机“拆除”只打开它们，不直接拆。成功掉落同一种方块，箱子不是木材，篝火为熄灭状态；满背包时留在地面。松开、关窗、失焦、换物品、受击、超距、倒地或重新放入内容物均取消。电脑、触屏、键盘空格/回车共用长按模式。有限工具扣次、拆除和掉落在同一内存事务中结算，再随一致性快照保存，结算失败整次回退；崩溃回到最近完整提交。

被怪物正在拆除的建筑禁止玩家同时拆除，立即取消已有玩家进度；同tick竞争时怪物拆除状态优先。所有怪物停止拆除、死亡或被移除后才解除，玩家重新计时。大怪拆墙/柱10秒、栅栏3秒，均为现实时间；寻路代价采用相同耗时，不掉任何物资；怪物不能拆树和设施。玩家自己的采集耗时不变。

建筑移除、供暖取消与掉落生成属于同一内存操作及持久快照；结算失败回退，后台SQLite提交失败保留批次重试，不会既保留建筑又生成掉落。掉落保留原物品类型，设施搬走不会刷新战利品、商品或已支付材料。

地雷是一次性陷阱，不可拆回；[公园椅子和固定机枪](outdoor-facilities.md)是不可拆除的自然固定设施，不走容器拆除流程。

## 碰撞与通行

| 对象 | 阻挡移动 | 阻挡视线 | 阻挡玩家普通子弹 | 阻挡怪物子弹 |
| --- | --- | --- | --- | --- |
| 树 | 是 | 是 | 是 | 是 |
| 墙、柱 | 是 | 是 | 是 | 是 |
| 木门 | 关闭时是 | 关闭时是 | 关闭时是 | 关闭时是 |
| 栅栏 | 是 | 否 | 否 | 否 |
| 箱子、篝火、存钱罐、全部机器 | 是 | 否 | 否 | 是 |
| 木地板、地雷 | 否 | 否 | 否 | 否 |
| 公园椅子 | 否 | 否 | 否 | 否 |
| 固定机枪 | 否 | 否 | 否 | 是，命中消失并播放弹开音效 |

固定机枪右侧一格是下座出口，只允许铺设地板，不允许放置墙、栅栏、容器、机器或地雷。旧有障碍在入座时自动清理，内容物与存钱罐余额的保护规则见[固定机枪](outdoor-facilities.md#固定机枪)。

玩家彼此不阻挡，倒地玩家不挡怪物。站立玩家与怪物、怪物彼此通常碰撞；小怪对目标玩家击退受阻时允许临时成对重叠，不能借此穿墙或穿过其他实体，详见[怪物行为](../world/combat.md#怪物行为与攻击)。
