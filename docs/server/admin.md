# 管理员控制台命令

[返回项目首页](../../README.md) · [手册目录](../README.md) · [本组目录](README.md)

## 启用与访问

Windows PowerShell 和 Linux shell 使用相同参数：

```sh
uv run cold-world-game --host 0.0.0.0 --password your-server-password --save-path ./saves --admin "管理员 小雪"
```

- `--admin` 后是完整玩家 ID，大小写、空格与中文必须完全匹配。含空格时使用英文双引号。ID 为 1～64 个可打印字符，不能全是空白。
- 只有该 ID 登录后才显示右上角 `>_` 按钮；控制台默认折叠，普通玩家不显示按钮。点击后可输入命令，Enter 或“执行”发送，关闭按钮或 Esc 收起。手机支持触控和屏幕键盘，横竖屏均可使用。
- 控制台展开时停止移动、攻击及物品使用，收起后恢复正常操作。命令历史仅保存在当前浏览器会话，最多 80 行，不写入世界存档。
- 不传 `--admin` 就没有玩家管理员。权限取决于**本次启动参数**，不会写进存档或沿用上次启动配置；重启可指定另一 ID 或关闭管理员功能。
- 权限在服务端逐条校验，隐藏按钮不是权限依据。此游戏通过共享口令与玩家 ID 登录，不另设管理员密码；能抢先使用该 ID 登录的人也能获得权限。请仅向可信玩家分享口令，不要将这一机制当作公网身份认证。

## 命令语法

命令名与物品 ID 使用**区分大小写的英文标识符**，参数之间使用普通空格，不使用中文引号或全角符号。玩家 ID 可以是中文；含空格时用英文双引号包围。每次只能执行一条命令，最长 512 个可打印字符，不支持批量、脚本、系统命令或跨行输入。

| 命令 | 功能 |
| --- | --- |
| `help` | 显示全部命令与简短用法，不修改世界 |
| `items` | 列出所有有效英文物品 ID |
| `items SEARCH` | 按区分大小写的子串筛选物品 ID，例如 `items staff` |
| `give PLAYER_ID ITEM_ID` | 给**在线**玩家一个指定物品 |
| `heal PLAYER_ID` | 将**在线**玩家体温与饥饿恢复满条，倒地者立即恢复站立 |
| `tp PLAYER_ID X Y` | 将**在线**玩家传送到指定浮点坐标，受阻时选最近空地格子 |

## give

```text
give 小雪 defibrillator
give "旅人 小林" flame_staff
give 小雪 gun_machine
give 小雪 coin
```

每次生成一个物品：优先放入目标的 30 格背包，第一个空格；背包满时放入 10 格物品栏，第一个空格；两者都满则生成目标脚边的地面掉落物，不覆盖、不删除原物品。物品栏可能因此多一件物品，但不会强制切换当前选中格。

硬币 `coin` 是例外：直接给目标金钱属性加 1，不占格、不落地。枪械自带正常满弹药；回城法杖为 20 次，寒冰与烈焰法杖为 100 次；除颤器、手榴弹、急救包均为一个一次性物品，篝火为熄灭状态。所有物品 ID 可用 `items` 查询，物品用途见 [物品手册](../guide/inventory.md)。

## heal

```text
heal 小雪
heal "旅人 小林"
```

体温设为 36°C，饥饿恢复到至少 10；已经超过 10 的饥饿值保持原值，不会反向扣减。倒地者可立即移动和战斗，显示医疗光圈与十字号，不传送、不清除怪物、不补充物品或金币。给自己治疗也使用完整 ID。

## tp

```text
tp 小雪 12.5 -8.25
tp "旅人 小林" 0 0
```

X、Y 支持正负整数、小数和科学记数法，必须是有限数且绝对值不超过 10000000，与正常移动协议的坐标边界一致。NaN、Infinity、逗号小数和其他无效数字会返回英文错误，不修改世界。

指定位置的碰撞箱能落脚时，精确保留浮点坐标；若被树、墙、箱子、机器、篝火、栅栏或怪物阻挡，则在整数格中心中寻找距**指定坐标**欧氏距离最近的可落脚位置。**木地板算空地，可正常传送**；回城法杖也采用这一规则。同距离时优先远离最近怪物格，最终按 x、y 稳定排序，不会随机跳到远处。

允许将倒地玩家传送，也允许管理员传送自己；不治疗、不扣法杖次数。目的地区块未生成时使用当前版本生成器；不重刷旧区块。落点与生成内容一起保存，失败整次回滚。成功在原地与落地处播放和回城法杖一样的法阵、光束与闪现 PNG 动画，清空旧移动/攻击/容器状态并递增移动修正及传送序号，过时位置上报不能把玩家拉回。

## 结果、错误与保存

命令的成功结果与报错均使用英文；其中的玩家 ID 按原文显示，中文 ID 不会被翻译。界面标题、按钮、提示仍随中英切换。常见错误：

| 英文结果 | 含义 |
| --- | --- |
| `Player does not exist: ...` | 该 ID 从未在此世界创建 |
| `Player is offline: ...` | 角色存在但不在线；不会给离线角色修改状态或发物品 |
| `Unknown item ID: ...` | 物品标识符无效，使用 `items` 查询 |
| `Unknown command. Use help for available commands` | 命令名错误或不是英文命令 |
| `Usage: ...` | 参数数量不正确 |
| `Invalid quoting; ...` | 引号未闭合或使用了不正确的转义 |
| `Only the configured server administrator ...` | 无管理员权限；伪造客户端请求同样被拒绝 |

发物品、金币、脚边掉落与治疗均在服务器 SQLite 事务成功后才确认；写盘失败整次回滚，不留下半次操作或成功动画。写盘故障会暂停世界，保留数据库并处理故障，不要盲目重发。连接中断或超时可能发生在提交之后：先查看玩家状态再重试，避免重复发放。`help`、`items` 不修改存档。
