# 界面与操作

[返回项目首页](../README.md) · [手册目录](README.md)

## 玩家界面以及游戏操作
玩家使用 WASD 在屏幕上移动，界面下方显示玩家物品栏（10 个物品），另有独立的 30 格背包。点击物品栏可以选中物品；选中斧头时，长按鼠标左键破坏方块，朝空地或怪物单击，对前方 3 格、180° 扇形内所有可见怪物群攻。玩家初次登录游戏时，物品栏中有一把满子弹的手枪、一个斧头以及一个满使用次数的打火机，背包初始为空。斧头和打火机不会因为重新登录而补发。

玩家可以使用滑轮切换当前选中的物品。当玩家选中食物时，长按空地 0.5s 可以吃掉这个食物。可乐、奥利奥和压缩饼干无需靠近篝火；其他食品仍要求玩家所在格子与已点燃篝火的曼哈顿距离在 1~3 格之间。当前饥饿值大于 10 时不能继续进食，也不消耗食品，等于 10 时仍可吃。玩家在箱子中心欧氏距离 2 格内时，左键点击箱子可以打开箱子，在屏幕上会显示一个箱子内容的悬浮窗，玩家可以把箱子中的内容移动到自己的物品栏中，或者把自己物品栏中的东西放到箱子里。

玩家在火堆或者熄灭火堆中心欧氏距离 2 格内点击它时，也会显示一个类似的悬浮窗。火堆有一个最多容纳 16 单位木材的燃料缓冲区和一个火种槽，玩家可以存取尚未燃烧的木材和火种；燃料缓冲区按单位计数，不受背包物品不能堆叠的限制。熄灭火堆有木材和可用火种时，可以点击“点燃”按钮点火。点火失败不消耗火种，已经燃烧的火堆不能重复点火。这些悬浮界面都可以使用 Esc 关闭或者点击悬浮窗自己的右上角的叉号关闭。

按 B 打开或关闭背包与制作面板。单击背包或物品栏中的物品查看侧边作用/用法说明，空格隐藏说明；双击、拖动或说明卡按钮转移，手机也可用整理模式指定格子，详见[物品说明卡](inventory.md#物品说明卡)。制作、建筑放置和拆除的具体规则见“木材系统”。容器窗口打开后，玩家离开交互距离或被墙等障碍遮挡时，窗口自动关闭。界面上的点击只操作界面，不会同时触发场景中的射击、进食或拆除；箱子、篝火、小猪存钱罐和三种机器只通过各自窗口内的专用按钮长按拆除，即使按 Shift 点击场景也只打开窗口。普通左键点击有效范围内的容器时优先打开，其他位置再根据当前选中物品执行操作；篝火需先取空储备木材与火种，拆除后掉落一个熄灭的篝火。容器交互、斧击和拆除均不能隔着阻挡视线的障碍物进行；建筑放置不检查玩家与目标之间的视线，允许隔着其他方块放置。

### 玩家列表

游戏顶部的“玩家”按钮可展开、收起玩家列表，按钮数字为在线人数。列表显示当前世界所有已创建玩家的名称、饥饿值、体温、金币与在线状态，不受角色之间距离限制；在线玩家始终在上方，离线玩家按最近登录时间从近到远排列，自己另有“你”标记。在线卡片使用暖色像素头像、青绿色边框和实心状态灯，离线卡片使用冷色头像、蓝灰边框与空心状态灯，文字也明确标记在线/离线，不只依靠颜色区分。

离线卡片的“上次登录”从该玩家最后一次成功登录的真实时间计算，不是游戏运行时间，也不是退出时间。距离登录不超过 5 分钟显示“刚刚”；超过 5 分钟且不足 1 小时按整数 `min` 显示，满 1 小时按整数小时，满 1 天按整数天，全部向下取整，不显示浮点数。世界暂停和服务器关闭期间仍计入这个真实时间间隔。旧存档缺少历史登录时间时显示“暂无记录”，该玩家下次登录后开始正常记录，不虚构历史时间、不改动其他玩家状态。

玩家列表通过登录后独立的每秒一次消息同步，浏览器只更新变化的卡片文字，折叠时不创建卡片，避免影响移动与战斗的高频画面。离线账号只出现在这个状态列表中，仍不恢复为场景实体、不参与模拟。断线时列表明确显示上次同步状态，重连后刷新。电脑和手机横竖屏均可展开、滚动、收起，打开背包、容器或帮助会自动收起列表，避免遮挡操作；支持完整中英切换。头像和名单图标为独立可替换 PNG。

游戏界面左上角会显示当前是第几年、当前的季节、游戏内时间、当前是什么季节的第几天。玩家物品栏上方会有两个彩色条，用来描述玩家的饥饿值和温度值。左上角还会显示玩家当前的坐标以及系统当前帧率。游戏界面和游戏服务器使用 websocket 实时通信，在游戏窗口没有关闭的前提下，游戏支持自动的断线重连以保证玩家的游戏体验。

服务器以 20Hz 更新世界、以 10Hz 推送附近的完整状态快照。推送按固定时间点调度，不因等待输入而逐次延后；处理过慢时跳过错过的推送，不排队补发旧快照。内置客户端不再要求无序号移动输入和停止指令的成功回执，物品操作的确认与所有错误仍正常返回。

本机角色由浏览器按每个动画帧直接计算移动、斜向归一化、冷饿减速和碰撞，按键或手机摇杆不再等待服务器快照，镜头也直接跟随本机位置。客户端约每 50 毫秒上报当前位置和实际速度，高频摇杆事件和键盘重复事件只更新本地输入，不逐次堆积消息；攻击、放置等操作前单独立即同步位置。服务器汇总位置而不重复积分，不做移动速度反作弊；旧客户端未启用该模式时仍沿用服务器移动。客户端使用与原规则一致的身体半径、逐段碰撞和沿墙滑动，不穿过墙、树、建筑、怪物或未生成区块。

其他玩家与怪物按服务器位置历史逐帧插值，不再直接用每包最后一刻的瞬时速度控制显示，避免快照到达时反复加减速、停步和切换跑动帧。显示缓冲根据快照抖动在约 120～280 毫秒之间调整，时间线缓慢校准而不随消息跳变；动画朝向与步频使用实际画面位移。缓冲短暂不足时用最近两份位置的平均速度继续移动最多 300 毫秒，再平滑减速，额外外推距离不超过约 420 毫秒的路程，静态碰撞仍生效，避免短暂写盘延迟造成反复急停。怪物决策与伤害仍由服务器统一结算，不在每个浏览器各自抽取 AI 或掉落。受击击退、失温倒地使用移动版本号校正，过时的位置上报不能抵消击退；本机显示平滑过渡，实际位置立即更新。子弹独立即时显示，不使用角色缓冲，仍遵循穿墙、阻挡物与视野半对角线距离规则，不自行判定命中。

暂时没有快照时，本机仍连续移动，超过 1 秒无状态更新则停止，恢复后同步当前位置，不补跑后台时间；远端角色先消耗缓冲并进行有界外推，500 毫秒无快照后停止显示移动，子弹在断流 300～500 毫秒间减速并停止，避免无限外推。断线、重连、页面后台和世界暂停均清理或重建运动状态，已死亡或离开快照的实体立即移除。物品确认、伤害与冷却采用最新服务器结果，不等待运动显示。雪地背景缓存后复用，降低桌面和手机每帧的绘制负担。

游戏整体是一个俯视视角的 2D 游戏，需要设计各种方块在界面上的直观呈现，怪物需要显示血条，玩家也有饥饿条和温度条在自己的上方方便其他玩家观察（类似于血条）。饥饿条应当使用红色，温度条应当使用蓝色。

## 浏览器操作

界面支持简体中文和英文，默认中文。登录页和游戏右上角都有语言切换按钮：中文界面点击 **EN** 切换英文，英文界面点击 **中文** 切回中文。登录、状态栏、背包、合成、容器、物品说明、操作指南和错误提示会即时切换，无需刷新或重新连接，不改变角色、物品或存档。语言选择只保存在当前浏览器，刷新或下次访问时沿用；本地存储不可用时仍可切换，但不会跨刷新记忆。玩家 ID 不翻译，各窗口可以选择不同语言。

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动、瞄准 | WASD、鼠标 |
| 切换物品栏格 | 1–0、滚轮、点击快捷栏 |
| 射击、斧头攻击怪物 | 单击左键；斧头攻击瞄准方向前方 3 格、180° 范围的所有可见怪物，空挥也有刃光和刀风；步枪支持按住连发 |
| 砍树、拆墙、进食、急救 | 长按左键；拆除计时按目标种类执行，进食与急救包使用需 0.5s，急救包不用火 |
| 迅捷戒指 | 必须放在物品栏并选中，当前体温/饥饿下移速乘3；无需点击使用，切到其他格即失效；手机点选后使用摇杆，倒地仍不能移动 |
| 伏特加与警长徽章 | 伏特加选中后长按左键0.5秒，无需火，30秒体感恒30°C；徽章放在任意随身格子被动增强对小怪/快速怪的所有武器伤害，不叠加 |
| 使用回城法杖 | 选中后长按左键 1.5s；松开取消，成功消耗 1 次，初始 20 次，无需火，倒地可用 |
| 使用除颤器 | 选中后对准 2 格内倒地的其他在线玩家，长按左键 1.5s；手机直接长按目标或点选后长按“使用”，成功消耗一个 |
| 打开附近箱子、篝火 | 对准容器左键 |
| 建造 | 选中建筑后单击左键，预览为初步判断，最终以服务器校验为准 |
| 拆除容器 | 箱子/篝火/售货机/火柴机：打开窗口，选中斧头长按窗内拆除按钮 1.5 秒；箱子必须清空，篝火必须取出储备木材与火种，回收为熄灭的篝火 |
| 背包与合成、帮助 | B 同时打开背包和合成，I 为兼容快捷键；H 打开帮助 |
| 关闭面板、丢弃物品 | Esc、Q |
| 整理与存取 | 背包、物品栏和容器之间拖到空格；点击查看说明，双击或说明卡按钮移入物品栏；Shift 点击随身物品存入已打开容器 |
| 丢到地面 | Q 丢弃当前物品栏选中物品，或将物品拖到场景中；沿鼠标方向最多 2 格，受阻时取障碍前最远可用落点 |

篝火面板可存取木材、放入/取回火种并点火。制作面板包含“两份木栅栏 → 一份木材”的回收配方。关闭或切走窗口会停止移动和长按攻击；帮助与制作面板不是暂停菜单。网络断线会自动重新登录并恢复服务器快照，未确认的制作、转移等操作不会自动重放。点击“离开”断开当前角色连接并返回登录页。

## 手机浏览器操作

根据移动设备信息和触屏粗指针识别手机/平板，而不是仅按窗口宽度判断；电脑缩小窗口不会出现手机摇杆。手机场景铺满可见区域，必要按钮和物品格至少为 44 CSS 像素，登录输入字体至少为 16px。横屏和竖屏分别排布控件，适配屏幕安全区与浏览器可视高度，不请求强制转屏或全屏：开启转屏锁定后，在当前方向照常游玩。屏幕旋转或可视区域改变时取消正在长按的操作，重新触摸即可继续；切到后台、失去焦点或断线也会停止移动和攻击。

| 操作 | 手机触屏 |
| --- | --- |
| 移动 | 左摇杆，松开停止；支持同时移动、瞄准和射击 |
| 瞄准 | 右摇杆，或点按/拖动场景指定位置；松开后保留相对角色的瞄准方向，单点场景不直接攻击 |
| 攻击、使用物品、打开容器 | 点“使用”攻击或打开瞄准的附近箱子/篝火；步枪连发、砍树、拆墙、进食、急救和回城需要按住，急救包与回城法杖无需火，斧头点按一次向瞄准方向挥出半径 3 格、180° 群攻，空挥也显示刃光并播放刀风 |
| 建造 | 在物品栏选中建筑，瞄准可放置位置后点“放置” |
| 拆除容器 | 箱子/篝火/售货机/火柴机：打开窗口，选中斧头长按窗内拆除按钮 1.5 秒；箱子必须清空，篝火必须取出储备木材与火种，回收为熄灭的篝火 |
| 丢弃 | 点“丢弃”扔出当前手持物品，沿瞄准方向最多 2 格，阻挡处理与电脑相同 |
| 背包与合成 | 点顶部“背包”，30 格背包和配方同时显示；打开面板时隐藏摇杆并停止移动，物品栏仍可使用 |
| 装备、快速拿取 | 点背包物品放进物品栏空格；点箱子物品收入背包 |
| 指定格子转移 | 面板内点“整理物品”，先点源物品，再点背包、物品栏或箱子的目标空格；再次点同一物品取消选择，点其他物品更换选择；选中木材后也可点篝火燃料区，火种可转入空火种格 |
| 从背包/容器丢到地面 | 整理模式选中物品后点“丢弃选中”，无需先腾出物品栏；使用打开面板前的瞄准方向 |
| 切换物品和关闭面板 | 物品栏可横向滑动，10 格互相独立且不缩小；物品面板可以上下滚动，顶部关闭按钮始终可见 |

篝火的存取木材、存取火种和点火按钮均可直接点按；触屏物品转移立即显示本地预览，服务器原子保存后确认；失败或断线则撤销预览，不会复制或丢失物品。中英文切换同样覆盖手机摇杆、操作按钮、整理提示和操作指南。手机浏览器首次触摸页面后解锁音效，不需要连接键盘或鼠标。

子弹使用加粗、延长的红色发光弹道和亮色内芯，怪物子弹偏玫红，在雪地和夜间均保持醒目；这只改变视觉表现，不改变速度、射程或命中范围。每枚子弹的 `owner` 标记发射者 ID，命中计算排除发射者本人，但玩家子弹仍可击中其他在线玩家。玩家子弹的初始坐标严格等于发射瞬间的玩家坐标，另记录 `origin_x`、`origin_y` 和 `spawned_at`；枪口特效也在角色坐标上播放。浏览器首次看到刚发射的子弹时从记录的原点连续向外显示，不直接从快照中已经飞远的位置冒出，拖尾不伸到发射原点后方；重连或读取旧在途子弹不回放历史发射。旧存档缺少新增字段时使用空缺省值，保留原子弹及其位置。开枪（含步枪连发）、成功进食、成功放置建筑、玩家受击均有音效，手枪、霰弹枪、步枪分别使用不同音色。斧头朝空地或怪物挥动时有一次双段刀风声和半圆刃光，实际命中另有命中声，怪物近战有攻击声；持续拆除时每 0.3 秒最多发出一次砍击声，拆成后额外播放碎裂声，怪物拆墙也有相应反馈。音效只在服务器确认动作后播放，射速或挥斧冷却、体温不足、进食条件不满足或放置失败时不会误响；斧头朝空地或超距怪物空挥仍播放刀风并消耗冷却。怪物近战、怪物子弹和其他玩家子弹造成的伤害均播放受击声；霰弹枪一次开枪只响一次，对同一玩家造成的伤害和受击声也只结算一次。附近其他角色的动作也有随距离衰减的音效。

右上角“音效”按钮可静音并记住本机设置。浏览器需要先点击页面或按键才能启用声音；只有当前前台且聚焦的窗口播放，避免多个角色窗口重复响。断线重连不重放历史音效，后台恢复后也不补播旧声。十四个独立 WAV 文件存放在 `cold_world_game/static/audio/`，替换及重新生成方式见 [音效资源](audio.md)。

勾选“在本机记住名字与口令”后，浏览器使用本地存储记住登录信息；口令保存在当前浏览器中，请勿在公共电脑勾选。每个在线窗口保持自己连接时的身份，不会因另一个窗口记住了新名字而切换角色。

所有场景、角色、怪物与物品贴图均为独立 PNG，位于 `cold_world_game/static/assets/`；替换方式和美术源脚本见 [美术资源](assets.md)。前端源代码位于 `cold_world_game/static/js/`，页面位于 `cold_world_game/templates/index.html`，通用样式位于 `cold_world_game/static/css/game.css`。手机设备识别与触屏输入独立放在 `cold_world_game/static/js/mobile.js`，手机布局位于 `cold_world_game/static/css/mobile.css` 并限定在手机模式下生效，均随 Python 包一起分发。

人物（自己与其他玩家）以及三种怪物均有上、下、左、右四向立绘，每个方向包含独立站姿与 4 帧跑动差分。动画根据客户端逐帧显示的实际位移播放，停步保持最后朝向，碰墙不会原地跑，失温倒地时停止跑动；受冷或饥饿减速时步频同步放慢，不改变移动速度或碰撞规则。五套常态动画分别保存在 `player_motion.png`、`player_other_motion.png`、`monster_small_motion.png`、`monster_big_motion.png`、`monster_fast_motion.png` 中，另有三套 `monster_*_frozen_motion.png` 冰冻差分，共八张 480 × 384 的透明 PNG 图集，可按说明逐帧替换；快速怪及冰冻怪物均按自身实际位移播放跑动差分。

寒冰法杖与斧头同样通过桌面左键或手机攻击按钮单击挥动，不需要长按；使用相同的攻击范围、半圆刃光和刀风声。冰蓝刃光也采用预生成的八方向 PNG，点击立即预览，伤害、冰冻和剩余次数由服务器原子确认；具体规则见 [战斗与怪物](combat.md#寒冰法杖)。

烈焰法杖也用同样的单击方式和八方向挥杖 PNG，初始 100 次，怪物身上叠加共享的小火苗动画。手榴弹与金币榴弹炮则需瞄准后持续长按左键 0.5 秒；手机可直接长按场景落点，或用瞄准摇杆指定位置后长按“使用”。松开会取消未完成的蓄力，投出后飞到指定坐标爆炸；金币榴弹炮继续按住可每秒发射一次，每次扣 1 金币。两者只伤怪物，不伤玩家或建筑，规则见 [爆炸武器](combat.md#手榴弹与金币榴弹炮)。

攻击与拆除另有朝目标挥斧、爪痕、枪口闪光、建筑震动和木屑飞散效果；怪物与玩家受击有红色冲击与短暂抖动，本人受伤时屏幕边缘闪红。死亡使用 `monster_small_death.png`、`monster_big_death.png`、`monster_fast_death.png`，其余特效使用 `fx_*.png`，均为可替换的六帧透明 PNG 图集。快速怪的静态图 `monster_fast.png`、四向跑动与死亡图集均由小怪原图变色生成并独立导出，可单独替换；攻击、受击和死亡音效沿用小怪。音画共用服务器实际动作事件，重复快照不重复播放，重连不补播旧动画；电脑和手机共享同一套反馈。

选中追踪导弹后，电脑单击左键发射；手机使用右摇杆/点场景设置初始方向，再点“使用”。方向只影响起飞，实际锁定发射瞬间离自己最近的怪物；长按不连发，点击附近容器也按射击处理。详见 [追踪导弹](combat.md#追踪导弹)。

新增有限武器/用品操作与数值见 [扩展图鉴](expansion.md)：新自动枪可按住连发，其他新枪单击；新近战单击且空挥扣次数；榴莲/医疗/回城用品长按，榴莲皮与其他投掷物在手机可直接长按落点。物品说明显示各自实际长按时间与限制。
