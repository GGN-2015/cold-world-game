# 采集、制作与建造

[返回项目首页](../README.md) · [手册目录](README.md)

本册说明材料、基础建筑和共用操作。所有容器与机器的功能、容量、价格及生成概率统一见[设施手册](machines.md)；物品丢弃与拾取见[背包手册](inventory.md#丢弃与拾取)。

## 材料与基础建筑

### 木材

![木材](../cold_world_game/static/assets/wood.png)

- **名称与标识**：木材 / Wood / `wood`。
- **获取方式**：砍树每棵随机1～3个；自然箱50%概率生成1～5个；拆木墙/地板、回收栅栏及机器兑换也可获得。
- **效果与数值**：基础制作原料和篝火燃料，每件独占1格。
- **操作方式**：按B在合成面板制作，或存入篝火燃料槽；普通木材不是可直接放置的方块。
- **消耗与限制**：按配方或燃烧消耗；不能通过循环制作、拆除或回收增殖。

### 木栅栏

![木栅栏](../cold_world_game/static/assets/fence.png)

- **名称与标识**：木栅栏 / Wooden fence / `fence`。
- **获取方式**：1木材制作2个，或拆下已有栅栏。
- **效果与数值**：阻挡移动，不挡视线和双方子弹。
- **操作方式**：选中后左键放置；斧头在3格内对准长按0.5秒拆除。
- **消耗与限制**：放置消耗1件，玩家拆除掉1个栅栏而非木材；2栅栏可回收1木材。大怪拆除不掉物资。

### 木墙

![木墙](../cold_world_game/static/assets/wall.png)

- **名称与标识**：木墙 / Wooden wall / `wall`。
- **获取方式**：1木材制作1个、自然房屋墙柱，或建材机器兑换。
- **效果与数值**：阻挡移动与视线，双方子弹均可穿透；柱子完全按木墙结算。
- **操作方式**：选中后左键放置；斧头在3格内对准长按1.5秒拆除。
- **消耗与限制**：放置消耗1件，玩家拆除得1木材；无设施八邻域间距限制。大怪拆除不掉物资。

### 木地板

![木地板](../cold_world_game/static/assets/floor.png)

- **名称与标识**：木地板 / Wooden floor / `floor`。
- **获取方式**：1木材制作1个，或建材机器兑换。
- **效果与数值**：玩家与怪物可走，视线和子弹可穿过，也可传送落脚；地板格不刷怪。
- **操作方式**：选中后左键放置；斧头在3格内对准长按0.5秒拆除。
- **消耗与限制**：放置消耗1件，拆除得1木材；地板仍占建筑格，不能叠放其他建筑。

## 制作配方

按B同时打开背包与合成，无需工作台或制作时间。共同检查背包和物品栏，优先从背包取料；产物优先放背包，再放物品栏。扣料后必须装得下全部产物，否则整次失败。制作、产物和保存原子完成。

| 配方标识 | 完整投入 | 完整产物 |
| --- | --- | --- |
| `fence` | 1木材 | 2木栅栏 |
| `wall` | 1木材 | 1木墙 |
| `floor` | 1木材 | 1木地板 |
| `chest` | 2木材 | 1箱子 |
| `campfire` | 1木材 | 1熄灭的篝火 |
| `recycle_fences` | 2木栅栏 | 1木材 |

## 放置规则

建筑须在物品栏中选中；鼠标指向显示绿/红放置预览，左键单击放置1个，长按不连续放，右键不建造。手机点“放置”。服务器最终确认，成功才消耗物品。

- 落点须在玩家欧氏距离3格内、已生成、没有其他建筑/树木或重叠实体，不能堵塞必须保留的出生通路。
- **不检查放置视线**：中间有墙或其他方块不单独导致失败，距离、空位和其余条件仍有效。
- 箱子、篝火、存钱罐与所有机器彼此在八邻域内不能相邻，包括斜对角；木墙、栅栏和地板不受这一间距规则约束。
- 左键点击已有容器通常优先打开窗口；投射用品瞄准行为见[操作手册](controls.md)。

## 采集与拆除

站立、选中斧头，在3格内对同一树或基础建筑长按左键；树0.5秒，栅栏0.5秒，墙1.5秒，地板0.5秒。必须保持交互路径畅通。松开、换物品/目标、超距或倒地会清空进度。

**箱子、篝火、存钱罐和所有机器统一走窗口拆除**：2格内打开窗口，取空物品/燃料/火种/余额，再选斧头长按窗口内拆除按钮1.5秒。场景点击、Shift点击或手机“拆除”只打开它们，不直接拆。成功掉落同一种方块，箱子不是木材，篝火为熄灭状态；满背包时留在地面。松开、关窗、失焦、换物品、受击、超距、倒地或重新放入内容物均取消。电脑、触屏、键盘空格/回车共用长按模式。

被怪物正在拆除的建筑禁止玩家同时拆除，立即取消已有玩家进度；同tick竞争时怪物拆除状态优先。所有怪物停止拆除、死亡或被移除后才解除，玩家重新计时。大怪拆墙/柱3秒、栅栏1秒，不掉任何物资；怪物不能拆树和设施。

建筑移除、供暖取消与掉落生成一起保存，写盘失败全部回退，不会既保留建筑又生成掉落。掉落保留原物品类型，设施搬走不会刷新战利品、商品或已支付材料。

## 碰撞与通行

| 对象 | 阻挡移动 | 阻挡视线 | 阻挡玩家普通子弹 | 阻挡怪物子弹 |
| --- | --- | --- | --- | --- |
| 树 | 是 | 是 | 是 | 是 |
| 墙、柱 | 是 | 是 | 否 | 否 |
| 栅栏 | 是 | 否 | 否 | 否 |
| 箱子、篝火、存钱罐、全部机器 | 是 | 否 | 否 | 是 |
| 木地板 | 否 | 否 | 否 | 否 |

玩家彼此不阻挡，倒地玩家不挡怪物。站立玩家与怪物、怪物彼此通常碰撞；小怪对目标玩家击退受阻时允许临时成对重叠，不能借此穿墙或穿过其他实体，详见[怪物行为](combat.md#怪物行为与攻击)。
