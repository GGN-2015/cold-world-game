# 安装与开始游戏

[返回项目首页](../../README.md) · [手册目录](../README.md) · [本组目录](README.md)

## 环境准备

安装 Python 3.11 或更新版本以及 uv，并确认终端中 `uv --version` 可用。下载项目后先进入含 `pyproject.toml`、`uv.lock` 的项目目录，再执行下方命令。首次 `uv sync --frozen` 需要能获取依赖；后续依赖已缓存时可离线启动。浏览器不需要安装 Python，只有运行服务器的电脑需要。

## 启动与浏览器游玩

后端代码位于 `cold_world_game` 包，使用 Flask 提供 HTTP、Flask-Sock 提供 WebSocket，依赖由 uv 和 `uv.lock` 管理。需要 Python 3.11 或更新版本。Windows PowerShell 与 Linux 终端均使用相同命令：

```sh
uv sync --frozen
uv run cold-world-game
```

默认只监听 `127.0.0.1:5000`，启动时在终端显示随机服务器口令和存档路径。允许局域网玩家连接，并指定口令及存档目录：

```sh
uv run cold-world-game --host 0.0.0.0 --port 5000 --password your-server-password --save-path ./saves
```

启动后在本机浏览器打开 **http://127.0.0.1:5000/**，填写玩家名字和终端显示的服务器口令即可游玩，不需要另外启动前端、安装 Node.js 或执行 npm 构建。同名角色恢复原存档；不同窗口可以使用不同名字同时加入，包括新建角色救援自己的倒地角色。

局域网其他电脑或手机访问 `http://服务器的局域网IP:5000/`，不要将监听地址 `0.0.0.0` 当成访问地址；手机与服务器连接同一局域网时，填写相同的服务器口令即可加入，手机中的 `127.0.0.1` 指手机自身而不是电脑。Windows/Linux 防火墙需要允许所选端口的入站连接。前端使用同源 WebSocket，HTTPS 部署时自动使用 WSS。使用支持 Canvas 2D、WebSocket、ES modules 和 Pointer Events 的现代浏览器；电脑使用键盘鼠标，手机自动启用独立触屏界面。

## 初次探索

输入名字与共享口令加入，右上角语言按钮可在中文与 English 间切换。新角色出生在区块 (0, 0) 的可达位置，初始有手枪、斧头与打火机。

先用斧头长按砍树，按 B 制作篝火，在三格内左键放置；打开篝火放入木材与火种后点火取暖。探索房屋寻找食物、武器、急救包与机器。B 可同时查看背包与全部合成配方；H 打开随时可查的操作帮助。手机用左摇杆移动、右侧瞄准区和“使用/放置”等专用按钮，转屏锁定不影响当前方向游玩。

离开时点击“离开”或关闭窗口；全员离线世界会暂停。下次使用相同名字恢复状态，不重新发放初始装备。具体规则见 [操作手册](controls.md) 和 [体温与急救](../world/survival.md)。

## 连接排查

- 页面无法打开：检查进程仍在运行、IP 与端口正确、监听地址为局域网可用地址、防火墙放行；不要修改或删除存档来处理网络问题。
- 口令错误：使用本次启动终端显示的口令；未指定口令时重启会生成新口令，可取消浏览器保存的旧值后重填。
- 名字已在线：关闭原连接或换一个名字；多个窗口不会自动抢占同名角色。
- 手机无法连接：不要填手机自己的 localhost；确保能访问服务器电脑，同一 Wi-Fi 的访客隔离也可能阻断设备互通。
- 没有声音：先点击页面解锁浏览器音频，检查“音效”按钮、设备音量和当前页面是否聚焦，见 [音效说明](../development/audio.md)。

完整参数、存档位置、备份与公网部署见 [服务器手册](../server/server.md)。
