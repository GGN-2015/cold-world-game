# 武器试验场与录像

## 网页试验场

```sh
uv run cold-world-game arena --host 127.0.0.1 --port 5001
```

打开 `http://127.0.0.1:5001/`。设置初始武器、怪群、地形、种子和 AI 策略后点“建立场景”。初始场景暂停，改完装备和环境后点“运行”。设置可在运行中调整，暂停时操作更容易复现。

| 编辑项 | 用法 |
| --- | --- |
| 快捷栏与背包 | 逐格放入或清空物品，可设已有弹药和耐久。斧柄等饰品按正常规则发挥效果，AI 会换弹或换备用武器 |
| 玩家状态 | 修改体温、饱食、金币、坐标和 AI 策略。倒地时自动暂停，可恢复体温后继续 |
| 地形 | 点击画面取坐标或直接填写坐标，放置或移除树、墙、门、栅栏、地板、篝火或固定机枪 |
| 怪群 | 设置怪物类型和数量，立即刷一波，或指定间隔与在场上限定时刷怪。可清除现有怪物 |
| 策略 | 随距离调整、守点躲弹、远程拉扯。决策会体现当前武器、目标、距离、移动和出手请求 |

武器、命中、敌怪、换弹、耐久和受击使用正式游戏规则。试验场用独立地图，可以控制怪群和环境，关闭自然温度、自然饥饿和自然刷怪。达到时限或点击“结束并保存”后，可以打开录像，也能用“重跑开局”恢复首次运行前的编辑。比较构筑时可保留相同的种子、地形和怪群，只替换一件饰品。

## 录制实际游玩

进入游戏后点“开始录制”，服务端从当前角色的视角录制玩家、物品、环境和引擎事件。点“停止并保存”后，顶栏出现“观看录像”。如果连接断开，服务器会把该次录制写入录像库。另一个玩家在同一场游戏中，可以单独录下自己的视角。

## 批量测试

在运行游戏或试验场的服务器上执行：

```sh
uv run cold-world-game replay-batch replays/scenarios.json
```

每个场景生成一份 `.replay` 文件和一行 JSON 摘要。其中的 `id` 可用来打开 `/replay/?run=<id>`，也可以在录像库中按批次名搜索。两种场景都在服务端按模拟时间运行：

- `survival` 使用真实地图、资源和生存规则。脚本的操作经游戏引擎校验。可传本地 Python 策略 `"policy": "my_policy:choose_actions"`，设置 `policy_every`（秒）和 `stop_on_downed`。策略接收 `seconds`、该角色的 `state`、上次 `previous_results`，返回由 `{"command": {...}, "reason": "..."}` 组成的列表。
- `arena` 使用试验场地图和 AI。脚本允许按模拟时间下达 `equip`、`tile`、`spawn`、`spawning` 等编辑，命令使用 `action` 字段。

```json
{
  "name": "探索策略检查",
  "runs": [
    {
      "title": "向东探索",
      "mode": "survival",
      "seed": 45,
      "duration": 30,
      "script": [
        {"at": 0, "command": {"type": "input", "move": [1, 0]}, "reason": "向东探路"},
        {"at": 1, "command": {"type": "input", "move": [1, 0]}, "reason": "维持移动"},
        {"at": 2, "command": {"type": "stop"}, "reason": "停下来检查周围"}
      ]
    },
    {
      "title": "带斧柄打单只小怪",
      "mode": "arena",
      "weapon": "axe",
      "intensity": "low",
      "duration": 15,
      "script": [
        {"at": 0, "command": {"action": "equip", "storage": "backpack", "slot": 0, "kind": "axe_handle"}}
      ]
    }
  ]
}
```

策略理由由脚本或 AI 提供，录像里的命中、掉落、伤害、操作成功与否来自引擎。

## 统一回放库

打开游戏服或试验场的 `/replay/`。可以筛选试验场、实际游玩、批量测试和上传，按名称或批次搜索。打开一局后可暂停、调倍速、拖动时间轴或点击事件跳转。画面旁显示角色装备、状态和 AI 决策，包含原始事件信息供排查。

三个入口都将录像写入同一个目录。默认使用工作目录下的 `replays/library/`。如果服务从不同路径启动，给游戏、试验场和批量命令指定相同的 `--replay-dir` 绝对目录。录像库和世界存档各自保存。服务器提供贴图和播放器，分享时发送下载得到的一个 `.replay` 文件即可。收到文件的玩家可在回放页上传，旧的 `.replay.gz` 也通过这里导入。启动试验场时会导入默认旧目录内已完成的试验场录像，自定义旧目录可用 `--history-dir` 指定。

录像库可由拥有当前服务口令的玩家访问。试验场仅监听本机时可省略口令。要向局域网开放，启动试验场时保留 `--password`。
