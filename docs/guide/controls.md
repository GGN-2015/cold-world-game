## 游戏界面

俯视场景以自己为中心，桌面雪原视野32×18格、16:9；手机按实际横竖屏适配，横向最多28格、纵向最多24格。角色上方红条表示饥饿、蓝条表示体温，怪物显示血条；顶部显示年份、季节、天数、时刻、气温、金钱及状态。

界面覆盖整个浏览器窗口，不局限于雪原画布。右上角可以打开玩家列表、背包/制作、帮助、音效、BGM与语言切换；管理员还有默认折叠的控制台入口，其他人不可见。背包说明位于左侧，容器/机器或合成位于右侧；窄屏说明默认收起，避免遮挡操作，见[物品说明卡](inventory.md#选择与说明卡)。

## 桌面操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 移动与瞄准 | WASD、鼠标 |
| 切换物品栏 | 1～0、滚轮、点击格子 |
| 单发枪、近战 | 左键单击；近战朝瞄准方向扇形群攻，空挥也有动画 |
| 自动枪械 | 按住左键，按物品自身冷却连发 |
| 食用、治疗、救援、回城 | 选中后长按左键，各物品时长见图鉴 |
| 投掷物、金币榴弹炮 | 对落点长按；金币榴弹炮可持续按住重复发射 |
| 砍树、拆墙/地板/栅栏 | 选中斧头，对同一目标长按 |
| 打开容器或机器 | 2格内左键点击 |
| 坐椅子或固定机枪 | 2格内点击未占用座位；移动离开，椅子也可再次点击起身 |
| 固定机枪射击 | 坐上后瞄准并长按左键，200发用尽即止 |
| 拆容器或机器 | 打开窗口并取空，选斧头长按窗口内拆除按钮1.5秒 |
| 放置建筑 | 选中建筑后左键单击，不能用右键或长按连放 |
| 背包与合成 | B同时打开，I也可打开 |
| 查看物品说明 | 面板内单击随身物品；窄屏点标题旁“物品说明”展开 |
| 转移物品 | 拖放、双击、说明卡按钮或Shift点击，见[背包手册](inventory.md) |
| 丢弃 | Q或拖到场景，沿瞄准方向最多2格；斧头禁止丢弃但可存箱 |
| 帮助、关闭面板 | H、Esc |

手持移动装备选中后直接用移动键，不用点击激活；随身被动装备不用选中。主动用品请朝空地或正确救援目标使用，避免附近容器交互优先。弹药、范围、冷却与操作限制统一见[武器](../items/weapons.md)、[食品](../items/foods.md)和[工具](../items/tools.md)。

松开、失焦、切换物品或界面会取消未完成长按；转屏后也必须重新按下。帮助、背包和控制台不是暂停菜单。点击“离开”断开角色并回到登录页；断线自动重连，不重放未确认的物品操作。

## 手机操作

检测触屏设备后启用独立大号按钮和双摇杆，不影响桌面键鼠。左摇杆移动；右摇杆或点场景瞄准，松开右摇杆保留方向。点击或长按“使用”按当前物品执行单击/长按操作；手榴弹等也可直接长按场景落点。建筑使用独立“放置”，丢弃用“丢弃”；斧头不能丢弃。

物品栏可横向滑动。打开背包后，用说明卡按钮或“整理物品”选择来源和目标空格；丢弃选中在斧头上禁用。容器与机器仍用窗内长按按钮拆除，不能在场景按一下就拆掉。

游戏适配横屏、竖屏、安全区域和浏览器工具栏变化，不要求关闭转屏锁定或进入全屏。画布大小随可见区域调整，屏幕方向变化停止当前长按，重新触摸即可继续；移动速度、世界距离与伤害不随屏幕尺寸改变。

手机可直接点座位或瞄准后点使用坐下，固定机枪用瞄准摇杆加长按使用；移动摇杆会起身。机枪2格内有怪物不能坐上，完整规则见[户外设施](../building/outdoor-facilities.md)。

## 玩家列表

列表默认折叠，展开显示名称、饥饿、体温、金币和在线状态。在线优先、按名称排序，以绿色状态点和高亮卡片区分；离线用低饱和样式，并按上次登录时间倒序，缺记录放最后。离线数据是保存状态，不表示人物仍在地图上。

距上次登录≤5分钟显示“刚刚”；之后不足1小时按整分钟、不足1天按整小时、其余按整天向下取整。使用服务器真实时间，不随游戏暂停停止计时；没有记录显示暂无记录。连接断开时明确为上次已知状态。名单约每秒独立更新，不挤占高频世界同步。

## 语言与音效

登录页和游戏右上角均有语言按钮：中文点EN切英文，英文点中文切回。所有菜单、提示、说明和错误即时切换，不刷新、不重连，ID和协议标识不翻译。偏好存在本机；禁用本地存储仍可当次切换。

开枪、挥动、受击、拆除、放置、进食、怪物攻击/死亡有对应音画反馈，首次点击页面后解锁浏览器音频。右上角可静音，详细资源与播放规则见[音效](../development/audio.md)。运动预测与卡顿排查见[实时性与性能](../development/performance.md)。

BGM按钮独立控制低音量钢琴配乐，昼夜选曲、威胁评分及淡入淡出见[背景音乐](../development/music.md)。
