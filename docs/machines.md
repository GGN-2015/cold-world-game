# 容器、篝火与功能机器

[返回项目首页](../README.md) · [手册目录](README.md)

## 共用交互规则

本册统一收录箱子、篝火、存钱罐与全部交易机器，按用途分类。同类条目均提供名称与标识、获取方式、效果与数值、操作方式、消耗与限制；交易设施另列完整兑换表。这里是设施功能和价格的唯一图鉴，地图只说明生成规则，建造手册只说明共用放置与回收流程。

点击欧氏距离2格内、交互视线畅通的设施可打开窗口，同时显示背包。电脑使用鼠标，手机直接点设施或瞄准后点“使用”。武器瞄准操作优先时，请先换成斧头等非投射用品。搬运须取空内容物（篝火含燃料和火种、存钱罐含余额），选中斧头或电锯，在窗口内长按拆除1.5秒；成功掉落同一方块而非木材。机器无商品库存可取，但实际容器内容仍须为空。

所有设施均占一格、阻挡移动和怪物子弹，不挡玩家子弹，怪物不能拆除。玩家放置时要求3格内合法空地，所有设施互相在八邻域不能相邻；没有放置视线限制。自然生成同样尊重间距、出生位置、入口和已有通路。拆除取消条件与完整放置规则见[采集、制作与建造](building.md)。

## 交易与空间规则

交易从30格背包与10格物品栏共同取料，金币直接扣金钱属性。产物先放背包，再放物品栏；输入消耗腾出的格可容纳产物，但必须一次装下全部结果，空间不足不扣款、不吞料、不丢一部分到地上。交易、状态变化与保存整次提交或回滚。每件产物保留自身的篝火、饥饿、选中和次数限制，出售火种不代替燃料。

机器可以重复交易，但每次都支付完整输入；没有初始免费库存、定时生产、利息或免费弹药重置。搬走、放置、重连或重启不产生赠品或退款。自然生成概率是每房（枪械机为每建筑区块）的独立判定，成功但没有合规空位会跳过，不强行改造房间。

## 储物、取暖与共享资金

### 箱子

![箱子](../cold_world_game/static/assets/chest.png)

- **名称与标识**：箱子 / Chest / `chest`。
- **获取方式**：自然房屋有1～2个箱子；2木材制作1个，也可在营地建材售货机兑换。
- **效果与数值**：通常30格，每格1件、不可堆叠；自然战利品同时命中较多时保留全部成功结果，可带额外格位，不丢弃后判定成功的物品。
- **操作方式**：打开窗口后拖放；点击容器物品取到背包，Shift点击随身物品存入。
- **消耗与限制**：必须取空后才能拆除，回收箱子再次放置为空，不会重刷战利品。

### 篝火

![篝火](../cold_world_game/static/assets/campfire.png)

- **名称与标识**：篝火 / Campfire / `campfire`。
- **获取方式**：1木材制作1个，也可在营地建材售货机兑换。
- **效果与数值**：点燃后按曼哈顿距离1～3/4～6/7～9格分别提供30/20/10°C；取最近已点燃篝火，不叠加，墙不挡热。30°C时每现实分钟回温20°C，20°C时每现实分钟回温15°C；火光约覆盖30°C暖区，仅为视觉效果，不改变热圈或食用距离。最多储备16木材，每份燃烧6游戏小时（6现实分钟）。
- **操作方式**：打开窗口，放入木材及火种后点“点燃”；每次点燃消耗火种1次并开始燃烧1份木材，储备耗尽后熄灭。未耗尽的火种在30格背包有空位时自动收回，背包满则留在火种格，不转入物品栏；用尽则消失。自动续燃不再消耗火种。需要火的食品仍仅在1～3格内吃。
- **消耗与限制**：储备木材和火种均取空可拆除，即使仍在燃烧也可拆；剩余燃烧时间作废，不退当前燃料。掉落并再次放置的是熄灭、无燃料无火种的篝火。

### 小猪存钱罐

![小猪存钱罐](../cold_world_game/static/assets/piggy_bank.png)

- **名称与标识**：小猪存钱罐 / Piggy bank / `piggy_bank`。
- **获取方式**：每间自然房屋独立5%概率生成1个，无制作配方。
- **效果与数值**：共享非负整数金币余额，所有玩家看到同一数值，任何玩家均可取走；初始余额0，不出售商品。
- **操作方式**：窗口中输入正整数数量，点存入或取出，在玩家金钱和共享存款间转移；背包全满也能操作。
- **消耗与限制**：余额和内容物都为0才能拆除；余额不足整次失败，不会透支。数额及结果余额不超过9,007,199,254,740,991，多人操作按序原子保存。
