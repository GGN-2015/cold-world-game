# 体温、饥饿与生存状态

[返回项目首页](../../README.md) · [手册目录](../README.md) · [本组目录](README.md)

本册说明角色生存数值及其相互作用。食品逐件说明见[食品与饮料](../items/foods.md)，治疗、救援、回城和装备见[工具与装备](../items/tools.md)，点火与热圈见[篝火](../building/machines.md#篝火)。游戏没有独立的玩家血量条，体温承担受伤与倒地状态。

## 体温变化

玩家初始体温36°C，上限36°C、下限0°C，按实际经过时间逐tick结算，使用浮点数保存。以下“每分钟”均指现实时间，等于游戏内1小时。

| 当前体感温度 | 每现实分钟的体温变化 |
| --- | --- |
| ≥30°C | 恢复20°C，最多36°C |
| [20, 30)°C | 恢复15°C，最多36°C |
| [10, 20)°C | 不变 |
| [0, 10)°C | 降低1°C |
| [-10, 0)°C | 降低2°C |
| [-20, -10)°C | 降低5°C |
| <-20°C | 降低10°C |

体感通常取世界环境温度或最近已点燃篝火的温度，再计入随身保暖加值。同属性保暖装备只取最高值，不叠加。亢奋期间体感固定30°C，不再加保暖值，按每现实分钟20°C恢复；30秒最多恢复10°C，不是瞬间恢复满体温。跨越亢奋结束时刻的tick分别按两段体感温度结算。

### 低饥饿失温

饥饿≤1且体温高于18°C时，体温一律按-30°C体感结算，即每现实分钟降低10°C；篝火、保暖装备和伏特加亢奋均不能抵消这段降温，亢奋剩余时间仍正常减少。体温降至18°C后结束额外惩罚，低于18°C时按原有环境和增益结算，不会被饥饿额外冷却；若环境依然寒冷，正常降温仍会继续。

边界按“18°C及以下不受额外惩罚”处理；处在温暖环境时，仍饥饿的玩家可正常回暖到18°C，但不能跨过该阈值继续回暖。进食使饥饿>1后恢复正常温度结算。这个规则不直接改变食物或医疗用品的即时恢复效果。

## 饥饿与进食

初始饥饿10，下限0，不设10点上限。每游戏小时自然消耗1点，即每现实分钟1点，逐tick连续结算；保鲜饭盒可降低自然消耗，但不减少受击损失。

只有当前饥饿>10才禁止吃食品；等于10仍可吃，食品完整加值。例如10时吃恢复5点的食品后为15，随后必须降至≤10才能再吃。界面显示真实数值，进度条按10满格、超额标为已饱，存档不截断超额值。

即食食品无需火；需火食品须在已点燃篝火的曼哈顿距离1～3格内。状态饮料与医疗补给不是普通食品，饥饿超过10也可使用。医疗补给的饥饿恢复最多补至10、保留已有超额值，和可超额加值的食品不同。

## 移动与倒地

| 生存状态 | 基础移速（格/秒） |
| --- | --- |
| 体温≥18°C，饥饿>0 | 4 |
| 体温5～不足18°C，或饥饿为0，仅一种减速 | 2 |
| 体温5～不足18°C且饥饿为0 | 1 |
| 体温<5°C，倒地 | 0 |

选中的手持移动装备在上述移速上乘自身倍率，不能解除倒地；不同手持物品不能同时选中。玩家之间不阻挡移动。

倒地时不能移动、攻击、射击或采集拆除；可以操作背包和附近容器、制作、放置及点燃篝火、吃食品、治疗、回城或救助附近队友。所有怪物不再索敌、追击、攻击倒地者，游荡也不向倒地者偏置；倒地者不阻挡怪物。已经发射的怪物子弹同样忽略倒地者。玩家子弹仍可命中体温>0的其他玩家，体温≤0时不再命中。

体温恢复到5°C即可站起，达到18°C解除低温减速。队友可生火帮助恢复，也可使用救援用品；玩家可以用另一个浏览器窗口、不同ID登录并援救旧账号，旧账号须保持在线。没有自动重生或自动回营。回城本身不治疗，倒地传回后可能仍不能移动。

## 状态与暂停

亢奋按玩家在线模拟秒计时，重复施加刷新而不累加，界面显示剩余整秒。主动恢复完成后播放医疗光圈与红色十字；取消未完成长按不消耗，不播放成功反馈。

个人离线后人物从世界消失，体温、饥饿、个人状态与物品不变化；全员离线或停机还会暂停整个世界。恢复不补算离线消耗。物品消耗、恢复、状态改变和保存原子完成，保存失败全部回退。详见[服务器与存档](../server/server.md)。
