# 游戏与服务器手册

[返回项目首页](../README.md)

## 物品图鉴

| 手册 | 负责的内容 |
| --- | --- |
| [食品与饮料](foods.md) | 全部即食/需火食品、饥饿恢复、状态饮料及获取概率 |

- 哪里查全部机器的价格和生成概率？见[设施图鉴](machines.md)。
- 倒地后怎么办？见[移动与倒地](survival.md#移动与倒地)和[队友救援](tools.md#队友救援)。
- 为什么旧箱子不会刷稀有物品？见[地图生成与存档](world.md#地图生成与存档)。
- 多人走动卡顿怎么排查？见[实时性回归场景](performance.md#回归场景)。
