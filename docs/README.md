# 游戏与服务器手册

[返回项目首页](../README.md)

手册按玩法领域分目录组织，每组有独立目录。主题页介绍当前规则，同类对象使用统一结构与实际PNG；一个规则只在所属章节完整说明，其他页面通过相对链接引用。

## 主题目录

| 目录 | 包含的内容 |
| --- | --- |
| [开始与操作](guide/README.md) | 安装启动、浏览器加入、键鼠与触屏、界面、背包与物品转移 |
| [世界与生存](world/README.md) | 地图生成、日期季节、体温饥饿、状态、六类怪物与战斗 |
| [物品图鉴](items/README.md) | 食品饮料、武器、工具装备的PNG、获取、效果、操作和限制 |
| [建造、设施与经济](building/README.md) | 采集制作、材料建筑、箱子篝火、全部机器、户外座位和金币 |
| [服务器与联机](server/README.md) | 启动部署、连接离线、存档兼容、管理员命令和通信协议 |
| [开发、性能与资源](development/README.md) | 代码职责、手册维护、性能回归、PNG、音效和背景音乐 |

初次游玩从[安装与开始](guide/quick-start.md)阅读，再查[界面与操作](guide/controls.md)。想了解物品作用，可进入相应图鉴；材料与建筑在建造组，金币在经济册，容器和机器统一在设施册。

## 常用问题

- 浏览器访问地址是什么？见[启动与浏览器游玩](guide/quick-start.md#启动与浏览器游玩)。
- 物品介绍为什么不显示在机器上方？见[左侧说明与窄屏折叠](guide/inventory.md#选择与说明卡)。
- 为什么斧头不能Q丢弃？斧头可以存箱，但所有丢地入口都禁止，见[丢弃与拾取](guide/inventory.md#丢弃与拾取)。
- 箱子、篝火和机器怎么搬走？统一见[采集与拆除](building/building.md#采集与拆除)。
- 哪里查全部机器的价格和生成概率？见[设施图鉴](building/machines.md)。
- 倒地后怎么办？见[移动与倒地](world/survival.md#移动与倒地)和[队友救援](items/tools.md#队友救援)。
- 为什么旧箱子不会刷稀有物品？见[地图生成与存档](world/world.md#地图生成与存档)。
- 如何关闭BGM、如何按怪物切歌？见[背景音乐](development/music.md)。
- 多人走动卡顿怎么排查？见[实时性回归场景](development/performance.md#回归场景)。
