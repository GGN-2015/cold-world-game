# 游戏与服务器手册

## 开始游玩

1. [安装与开始游戏](quick-start.md)：Python/uv、Windows/Linux 启动、浏览器连接和初次探索。
2. [界面与操作](controls.md)：桌面键鼠、手机摇杆与按钮、横竖屏、双语切换、玩家列表和流畅显示。
3. [体温、饥饿与急救](survival.md)：环境温度、失温救援、食物与火种数值、急救包及医疗动画、回城法杖与传送落点。

## 完整玩法

- [世界、地图与季节](world.md)：坐标、随机房屋与箱子、机器、出生点、四季和年份、旧世界的新区域。
- [背包、物品栏与物品](inventory.md)：独立 10/30 格区域、箱子、掉落与拾取、原子转移、全部物品类别。
- [采集、制作与建造](building.md)：树木、柱子、木材、全部配方、篝火、放置限制与长按拆除。
- [机器交易与金币](trading.md)：两种机器的全部兑换、钱包、怪物金币掉落、机器采集与再放置。
- [武器、怪物与战斗](combat.md)：射速、穿墙穿透、友伤、击退、昼夜生成、快速怪、寻路和建筑拆除。

## 安装与维护

- [服务器、联机与存档](server.md)：完整命令行参数、口令、离线与暂停、SQLite、备份升级及部署边界。
- [后端协议](protocol.md)：HTTP/WebSocket、目录、输入、容器、交易、反馈事件、错误和兼容字段。
- [美术资源与前端开发](assets.md)：全部独立 PNG、四向动画、医疗/战斗/死亡图集、清单与生成脚本。
- [动作音效](audio.md)：十二个 WAV 的用途、替换生成、声音解锁、静音、距离衰减及去重。
