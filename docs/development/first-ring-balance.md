# 一区武器与饰品审阅表

下表左侧是当前游戏数值，右侧是后续调平用的提议。日常供暖、边界和可维修设备已经使用运行时规则。武器与新饰品的提议供逐项审核。现有 10 件饰品的 55 组两两组合（含重复）由物品审计逐对执行。

## 饰品及其组合效果

同一功能位的替代件取一件。距离、伤害、攻速、伐木、点火、控制、移速分别计算。不同功能可以同用，计算时先应用角色和武器主体，再应用该功能位的倍率和代价。法系标签武器才能享受法伤，带弹丸的冰晶卡宾枪可享冰冻修正，公共护甲与移动件仍可混搭。
