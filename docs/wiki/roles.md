# 条目定位

按当前可取得的武器、用品和可遇到的设施、怪物查用途。名称可打开完整机制和获取方式。

## 武器与弹药

| 条目 | 用途 |
| --- | --- |
| [斧头](../items/weapons.md#斧头) | 起步伐木和应急近战。无限使用，短攻击距离让长柄套与有限耐久武器都有价值。 |
| [连锁电锯](../items/weapons.md#连锁电锯) | 清出通道或成批伐木。能连砍半径 5 格内的树，整次只耗一次耐久，也能近距离群攻。 |
| [破片炸药](../items/weapons.md#破片炸药) | 把伤害集中在小范围，命中可一击打倒 24 血冰甲怪，需要更长蓄力。 |
| [撬棍](../items/weapons.md#撬棍) | 窄角处理单只怪。6 点伤能一击打倒雪地爬行者，覆盖面小于开山刀。 |
| [榴莲皮](../items/weapons.md#榴莲皮) | 吃完榴莲获得。短按松开可反复近战，长按可消耗一片换取单个目标的限时扎伤。 |
| [燃烧瓶](../items/weapons.md#燃烧瓶) | 一次点燃较大一片树和怪。带一瓶可以开路，灼烧给玩家留出撤退时间。 |
| [火球术卷轴](../items/weapons.md#火球术卷轴) | 可以复制的远程点火工具。引燃落点的树，火球经过的路线也会短暂亮起来。 |

| [火焰喷射器](../items/weapons.md#火焰喷射器) | 用一条火带点燃行进方向上的树，同时伤到带内的怪。携带汽油可以在密林里继续开路。 |
| [信号爆弹](../items/weapons.md#信号爆弹) | 把光投往远处固定位置，适合先看清雾中的通路或目标再靠近。 |
| [冰冻术卷轴](../items/weapons.md#冰冻术卷轴) | 可以复制的冰湖通行工具，暂时稳定湖面，让玩家正常走或抓紧铺地板。 |
| [冰霜弹](../items/weapons.md#冰霜弹) | 一次给怪群减速并稳住冰面较久，适合来不及复制卷轴时应急。 |
| [寒霜长矛](../items/weapons.md#寒霜长矛) | 隔一段距离控制单列目标。长射程配窄扇形，适合狭窄通道。 |
| [手榴弹](../items/weapons.md#手榴弹) | 一次处理成团的怪，或直接爆破密林中的树。 |
| [手枪](../items/weapons.md#手枪) | 起始远程自卫。射速较快，轻弹可与左轮共用。 |
| [猎人步枪](../items/weapons.md#猎人步枪) | 远距离逐个点杀，12 点单发可击倒 10 血小怪；连续开枪较慢。 |
| [寒冰法杖](../items/weapons.md#寒冰法杖) | 冻结正面扇形里的多只怪。对准一群进场的敌人使用，可以为后撤争取时间。 |
| [轻弹包](../items/weapons.md#轻弹包) | 给起步手枪和左轮续航，两把枪之间换用时仍能保留轻弹。 |
| [开山刀](../items/weapons.md#开山刀) | 通用扇面近战。伤害和间隔适合处理多只基础怪，每次有效命中消耗耐久。 |
| [步枪](../items/weapons.md#步枪) | 连续射击应付快速接近的怪。单发伤害较低，长按容易用光弹药。 |
| [步枪弹包](../items/weapons.md#步枪弹包) | 在随身步枪和固定火力之间分配弹药。一整包可以给固定机枪装填。 |
| [老式左轮](../items/weapons.md#老式左轮) | 用较高单发伤害省弹。可一枪处理 6 血的爬行者，容量只有 6 发。 |
| [霰弹枪](../items/weapons.md#霰弹枪) | 贴身爆发。在近距离让同一目标吃到多枚弹丸，或用散布压住并排的怪。 |
| [霰弹包](../items/weapons.md#霰弹包) | 给近距离散弹攻击补弹，每包四发，单发收益取决于命中弹丸数。 |
| [工兵铲](../items/weapons.md#工兵铲) | 在门口和撤退时推开追兵。长攻击距离和较强击退能换出走位空间。 |
