# 一区道具与机制定位

**待审核。** 每项先回答两个问题。玩家遇到什么情况时会特意带它？付出一个格子之后，它比替代品多解决什么？同名组列出的物品均按现行作用审查。合并、候补和改机制都是提案。

## 工具与道具

### 消耗品

| 道具 | 用在什么情况 | 取舍 |
| --- | --- | --- |
| [打火机](../items/tools.md#打火机) | 新手持续点火，照明、烹饪和取暖都靠它起步 | 保留基础火种。初始 20 次已经很充足，测试时留意备用火种是否一直没人拿 |
| [火柴](../items/tools.md#火柴) | 打火机丢失或耗尽时的低成本应急 | 保留单次和可购买的来源 |
| [引火棒](../items/tools.md#引火棒)、[火绒盒](../items/tools.md#火绒盒)、[防风火种](../items/tools.md#防风火种) | 三者现行差别主要是点火次数和来源 | 一区先留一种中等次数的备用火种；防风效果有对应天气后再考虑独立投放 |
| [汽油](../items/tools.md#汽油)、[柴油](../items/tools.md#柴油)、[煤油](../items/tools.md#煤油) | 目前都是 5 次点火，占格和用途相同 | 一区先只留一种液体火种。若汽油以后能补喷火器燃料，可以单独留下 |
| [暖宝宝贴](../items/tools.md#暖宝宝贴) | 到达暖区前体温告急，立即救急 | 单次回温，重点是救急效率和低占格 |
| [保温毯](../items/tools.md#保温毯) | 回温效果与暖宝宝重合，使用更慢 | 先合并；有撤离后持续保温等独立用途再恢复 |
| [口袋暖炉](../items/tools.md#口袋暖炉) | 冰湖或多段低温路，途中反复小幅取暖 | 多次储备，面对一次大幅失温时不如单次回满 |
| [保温壶](../items/tools.md#保温壶) | 同样用于分段取暖，现行主要差在次数和单次恢复 | 和暖炉留一个首测。若过冰湖确实需要不同的回温时机，再保留两档 |
| [急救包](../items/tools.md#急救包) | 又冷又饿，遭袭之后需要一次恢复两项 | 保留稀有全能急救，留意是否让普通暖宝宝和补给袋失去拿取价值 |
| [野外补给袋](../items/tools.md#野外补给袋) | 轻度受损时分两次补体温和饥饿 | 小修小补，优势是一个格装两次，用于面临多个风险的路线 |
| [葡萄糖补给](../items/tools.md#葡萄糖补给) | 无火时补 3 饥饿 | 同值即食食品可替代，一区先合并；以后有独立的急救条件再放回 |
| [除颤器](../items/tools.md#除颤器) | 队友倒在危险位置，尽量快救起 | 救援距离和速度更好，单人占格没有价值 |
| [复苏针](../items/tools.md#复苏针) | 有安全窗口时以较低成本救队友 | 贴身、用时长，对应能腾出时间的救援 |
| [救援信标](../items/tools.md#救援信标) | 快冻倒或困住时一次性撤回出生点附近 | 作为低门槛逃生底牌；撤回仍需补给 |
| [裂纹回城石](../items/tools.md#裂纹回城石)、[回城法杖](../items/tools.md#回城法杖) | 与信标通向相同地方，差别是次数和用时 | 一区首测留信标。若可重复回城能服务多人救援，再留一种。法杖 20 次有形成长期基地循环的风险 |
| [燃料补给包](../items/tools.md#燃料补给包) | 把多份木材压成一格带过边界 | 以开包步骤和携带成本换空间，适合长距离移动 |

| [拾荒手套](../items/tools.md#拾荒手套) | 走动时顺手捡地上掉落 | 区别只在拾取半径。若手测看不出其影响过路线和走位，先退出普通池 |

## 食品

食品差异先看能否立刻吃、占一个格能带多少饥饿值、是否连接战利品或加工。下面列的是现行用途。纯同数值同获取体验的食品可以合为一行规则，保留外观和名称作为风味变化。

| 食品 | 要解决的问题 | 是否值得独立规则 |
| --- | --- | --- |
| 奥利奥、芒果干、蜂蜜包、海苔卷、米饼 | 路上随手填一点饥饿 | 同一轻食档即可；奥利奥有怪物掉落渠道可单列 |
| 黄桃罐头、菠萝罐头、巧克力、芝麻饼、可乐 | 出门立即吃、值约 2 点饥饿 | 可合一档；可乐有售货机和怪物来源，仍能作为渠道差异 |
| 玉米罐头、花生米、小鱼干 | 中档即食口粮 | 可合一档；小鱼干有加工链 |
| 能量棒、混合坚果、焗豆罐头、牛肉干、压缩饼干 | 腾格给武器，把更多口粮装进一格 | 用中量与高量两档即可；牛肉干有加工链，饼干是长途高效口粮 |
| 榴莲 | 吃完还剩一件可开路的投掷物 | 保留，收益跨食品与开路 |
| 速冻火锅涮菜、方便面、速冻馄饨、沙丁鱼罐头、金枪鱼罐头 | 有火时转化基础口粮 | 压缩为一档或两档；沙丁鱼保留加工出口 |
| 速冻饺子、冷冻猪蹄、蘑菇汤、燕麦粥 | 有火时吃一份中量正餐 | 复用一档，燕麦粥可保留可买渠道 |
| 冷冻牛肉、冷冻羊肉、撒尿牛丸、冷冻披萨、咖喱饭、八宝粽 | 值得特意找一次火源的高量口粮 | 两个饥饿量级就够；牛肉可加工，八宝粽可作低概率风味奖励 |
| 伏特加 | 短时间穿过严寒 | 保留独立状态，携带时与口粮争一个格子 |

## 建筑与设施

| 条目 | 提供的决策 | 取舍 |
| --- | --- | --- |
| 木材、木墙、木地板、木门 | 同一批木材要在烧火、防弹、保温、保留进出口之间分配 | 各自影响的生存动作不同，保留 |
| 木栅栏 | 廉价延缓移动，玩家可隔栅栏射击 | 和挡枪弹、用于保温的墙区分 |
| 地雷 | 用掉一个格子提前防守或撤退 | 与手雷的即时投掷不同，需要预判怪物路径 |
| 箱子 | 为探索提供战利品；玩家箱临时存放交换物资 | 一键拿取降低重复搬运 |
| 篝火、固定供暖机 | 一个随身搭营，一个要找地点并维修换更好燃油效率 | 两者支撑不同的临时营地选择 |
| 硬币、小猪存钱罐 | 把怪物收益转成资源、多人临时共享余额 | 单人无需额外携带一台存钱罐，多人在交易附近更有用 |
| 自动售货机、弹夹机、自动医疗柜 | 按现场短缺选择通用物资、弹药或治疗 | 弹夹机只补弹药，枪械靠探索；补给价格要避免比出门搜更高效 |
| 自助火柴机、自助火种补给机 | 缺火种时花币挽救开局 | 交易目的明显重叠，合并到一个补火入口 |
| 自动口粮机、自助食品脱水机 | 没食物就花币补，或把手头冷冻食物加工为便携口粮 | 消耗资源路径不同，保留两种用途 |
| 营地建材售货机、木材压缩打包机 | 前者当场快速施工，后者把木材装进更少格子 | 选当前布防还是把资源带出当前区域 |
| 废材拆解回收机 | 将多余装备转换成可用材料 | 给候补物资一个低收益回收口，产出需小于主动搜刮 |
| 防寒装备裁缝机 | 用资源降低长期温度压力 | 只有保暖有明显路线收益时值得专设 |
| 队友救援补给机、远行应急补给站 | 分别为救队友和急撤补给 | 若一区只留少量应急用品，可合并到一个补给点 |
| 公园椅子 | 让多人有临时停歇和社交点 | 可保留场景氛围，避免在普通战利品额度内占比 |
| 完好固定机枪、待维修机枪、固定大炮（草案） | 控制线形怪群、把修理资源换为临时阵地、集中轰击怪群 | 初装弹、是否需维修和射击方式各自决定值不值得绕路 |
| 林间索道、断桥桥墩、路灯 | 分别处理密林、冰湖、迷雾 | 都用零件，但位置和跨越方法不同，可给同一维修工具多个实用目标 |

## 怪物

| 怪物 | 逼玩家解决的问题 | 设计取舍 |
| --- | --- | --- |
| 小怪 | 10 血的基础战斗与消耗基准 | 保留，测试普通场景时先用它衡量装备 |
| 雪地爬行者 | 行为慢但迫近，6 血提供低一档击倒阈值 | 让高单发武器和低成本武器的区别有可见结果 |
| 雪狐怪 | 8 血、中速，迫使玩家判断能否边走边打 | 和快速怪的区别是白天活跃、仍能被通常移速甩掉 |
| 快速怪 | 追得比玩家快，撤退时仍得反击或控制 | 强化控制、击退、短间隔枪的价值 |
| 冰甲怪 | 24 血，普通武器要多次投入 | 提供精确大伤害和破片炸药的用武场景 |
| 大怪 | 50 血、远程攻击和拆墙，逼玩家重新走位 | 防守压力来自射击与拆墙，区别于单纯血厚的冰甲怪 |
| 树精 | 扮成树并远程射击，打断直线砍伐 | 给密林的开路选择加入警觉与处理怪的成本 |
| 冰守卫、火守卫 | 曾设计为元素弱点和定点路障 | 目前生成关闭，等有适合守门的环境再讨论，近期平衡以实际生成的怪物为准 |
