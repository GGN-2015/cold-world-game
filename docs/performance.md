# 实时性与性能

[返回项目首页](../README.md) · [手册目录](README.md)

本册解释本机响应、多人平滑显示和性能验证。游戏规则见玩法手册，消息字段见[协议手册](protocol.md)，部署与存档维护见[服务器手册](server.md)。

## 本机即时响应

浏览器逐帧计算自己移动、碰撞和沿墙滑动，约50毫秒汇总上报；攻击、放置和丢弃前立即上报最终位置与瞄准。服务器汇总本机位置，不重复积分；怪物、伤害、冷却、消耗和掉落仍统一结算。

近战点击立即选择预烘焙的八方向六帧PNG并播放挥动音效，不等待网络往返。服务器用attack_id确认本机预览，匹配事件不重复播放；拒绝/失败取消预览，预览不结算伤害。物品转移同样即时预览，按请求序号合并确认，失败整体回退，不在客户端创建权威物品。

## 多人和怪物连续显示

按实体ID保存最多32份位置样本，在约120～280毫秒自适应缓冲上插值；世界显示时钟缓慢校准，不因新包跳变。朝向和跑动帧使用实际显示位移，避免网络节奏控制动画步频。

短暂缺样用最近两份位置平均速度外推最多300毫秒，之后平滑减速，额外路程不超过约420毫秒的移动量；500毫秒无状态时远端冻结。本机超过1秒无状态停止，恢复不补跑后台时间。子弹有独立即时通道，不等待角色缓冲，断流300～500毫秒间减速停止。

普通位置误差连续消除，不因超过某个距离就瞬移；移动修正序号保护击退，显式teleport_epoch区分真正传送。远端普通行走速度不超自身当前速度；追赶修正有上限，高速手持装备也不会把误差修正成三倍猛冲。移除/死亡立即生效，重连、后台、暂停和真正传送重建适用轨迹。

## 服务端时间预算

20Hz模拟、约10Hz世界同步，玩家名单独立约1Hz。寻路任务可暂停，轮转分批续算，每tick最多开始8个任务、共享约8毫秒搜索预算，普通批次约32个节点；封闭目标的候选格扫描也分批。已有合法路径继续移动，索敌、冷却与攻击不等待整次搜索完成。

静态建筑按实体ID保存脏数据与回滚记录，不在每次战斗复制或序列化全图。SQLite事务使用WAL及FULL同步，产出保存成功才确认；不能为降低延迟牺牲原子保存。未变建筑/背包不重复发，客户端复用静态碰撞网格、格子DOM及容器输入框。

## 绘制与资源预算

雪地纹理离屏缓存，按需重建；角色四方向差分、八方向武器刃光、受击/死亡/医疗/爆炸均离线生成PNG图集。怪物灼烧叠同一小火苗动画，不生成专属立绘或实时粒子。运行时只按时间选帧贴图，动画不驱动玩法。

音效按事件去重、距离衰减，避免重复快照产生音频风暴。资源替换见[美术](assets.md)与[音效](audio.md)，模块职责见[开发维护](development.md)。

## 回归场景

- 在实际往返约300毫秒的链路测试，而不是只在无延迟localhost测试；分别记录输入到本机画面、远端移动、服务器tick和绘制耗时。
- 大地图、多玩家同向同行、怪物达到70只并持续战斗；重点观察普通移动是否突然跳位、拐角是否反复急停、斧头点击是否等待回包。
- 往返转移背包/物品栏/箱子，包含高延迟、满格、多人竞争、写盘失败；本机预览立即，最终物品与SQLite完全一致。
- 手机横屏、竖屏和方向锁定下测试摇杆、长按、容器操作；选物品不得强迫滚动到说明，窄屏说明默认折叠。
- 模拟断线、重连、后台再返回、击退、倒地、传送和停止服务器；普通同行不能被误当作传送，取消动作不能重放成消费。

排查时分别量测服务器模拟/寻路、SQLite提交、JSON编码/差分字节、DOM更新与Canvas绘制，不把所有卡顿归咎于网络。保留世界与存档，不通过减少已生成地图或清空建筑来让测试看似流畅。
