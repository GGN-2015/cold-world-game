# 动作音效

## 文件与替换

音效存放于 `cold_world_game/static/audio/`，全部为本地 WAV 文件，不依赖外部音频网站或网络服务：

| 文件 | 用途 |
| --- | --- |
| `handgun.wav` | 手枪开火；大怪发射子弹时以较低音调播放 |
| `shotgun.wav` | 霰弹枪开火，一次射击只播放一次 |
| `rifle.wav` | 步枪开火，连发时每次实际出弹播放一次 |
| `eat.wav` | 食物成功吃掉时的咀嚼声 |
| `place.wav` | 建筑成功放置时的落地敲击声 |
| `hurt.wav` | 玩家实际受到怪物近战、怪物子弹或其他玩家子弹伤害时的撞击声 |

当前素材由项目内脚本合成，为单声道、22050 Hz、16 位 PCM WAV。替换时保留文件名即可，浏览器会自动解码采样率；推荐保留短音效，避免步枪连发时长尾叠加。修改后强制刷新浏览器。音效资源和前端脚本会随 Python wheel 一起分发。

源脚本是 `tools/generate_audio.py`，仅使用 Python 标准库，Windows 和 Linux 使用同一命令：

```sh
uv run python tools/generate_audio.py
```

重新生成会覆盖同名文件，手工替换前请自行备份。

## 播放规则

- 浏览器首次点击或按键后启用 Web Audio；没有声音权限时不影响游戏运行。
- 右上角“音效”按钮切换静音，设置保存在当前浏览器的本地存储中。
- 只播放当前前台、聚焦窗口的音效；切到后台或失焦立即停止正在播放的声音。
- 音效来源是服务器确认的瞬时动作事件，不是鼠标按下动作。失败的进食、建筑放置、空枪或射速冷却都不会发声；物品保存失败回滚也不播放。
- 受击声从统一伤害结算入口发布；自然降温和饥饿消耗不播放，子弹被墙挡住或未命中不播放。霰弹枪同一次射击命中同一玩家时只结算一次伤害，也只播放一次受击声。
- 附近角色的声音按距离衰减，18 格以外不播放；最大同时播放 24 个音效，避免过度叠加。
- 初次登录、重连和恢复前台不会补播历史声音，同一事件在多份快照里出现时只播一次。

`cold_world_game/static/js/audio.js` 负责本地资源加载、浏览器声音解锁、去重、衰减和静音。`world.py` 暂存待提交事件，在对应事务成功后发布；这些事件不写入 SQLite 存档。事件字段见 `docs/protocol.md` 的“瞬时动作反馈”。
