# 动作音效

[返回项目首页](../README.md) · [手册目录](README.md)

## 文件与替换

同一服务器 tick 内相同音色、相同音调的密集命中/死亡声合并为距离最近的一次；不同 tick 的连续攻击保留各自声音。群攻不会创建几十个同时播放的命中声源，避免噪声叠加、切断刀风和增加手机音频负担；同时发声总数仍限制为 24。

音效存放于 `cold_world_game/static/audio/`，全部为本地 WAV 文件，不依赖外部音频网站或网络服务：

| 文件 | 用途 |
| --- | --- |
| `handgun.wav` | 手枪开火；大怪发射子弹时以较低音调播放 |
| `shotgun.wav` | 霰弹枪开火，一次射击只播放一次 |
| `rifle.wav` | 步枪开火，连发时每次实际出弹播放一次 |
| `eat.wav` | 食物成功吃掉时的咀嚼声；急救包成功使用时复用该物品使用提示音 |
| `place.wav` | 建筑成功放置时的落地敲击声 |
| `hurt.wav` | 玩家实际受到怪物近战、怪物子弹或其他玩家子弹伤害时的撞击声 |
| `axe.wav` | 每次有效挥斧或挥动寒冰/烈焰法杖播放一次约 0.3 秒的双段“刷刷”刀风声，空挥也播放；群攻不会按命中数重复播放 |
| `hit.wav` | 怪物实际受到斧头、寒冰/烈焰法杖或子弹伤害时的撞击声 |
| `monster_attack.wav` | 大小怪物近战攻击声，大怪以较低音调播放 |
| `chop.wav` | 玩家或怪物持续拆除时的木质敲击声 |
| `break.wav` | 建筑实际拆除完成时的碎裂声 |
| `monster_death.wav` | 怪物死亡声，大怪以较低音调播放；与约 0.65 秒的死亡动画配合 |
| `throw.wav` | 手榴弹或金币榴弹炮成功投出一发时的短促抛掷声 |
| `explosion.wav` | 每次落点爆炸播放一次，不随受伤怪物数量叠加 |

当前素材由项目内脚本合成，为单声道、22050 Hz、16 位 PCM WAV。替换时保留文件名即可，浏览器会自动解码采样率；推荐保留短音效，避免步枪连发时长尾叠加。修改后强制刷新浏览器。音效资源和前端脚本会随 Python wheel 一起分发。

源脚本是 `tools/generate_audio.py`，仅使用 Python 标准库，Windows 和 Linux 使用同一命令：

```sh
uv run python tools/generate_audio.py
```

重新生成会覆盖同名文件，手工替换前请自行备份。

## 播放规则

- 浏览器首次点击或按键后启用 Web Audio；没有声音权限时不影响游戏运行。
- 右上角“音效”按钮切换静音，设置保存在当前浏览器的本地存储中。
- 只播放当前前台、聚焦窗口的音效；切到后台或失焦立即停止正在播放的声音。
- 本机合法挥斧在点击时立即播放刀风，不等待网络往返；服务端同一次确认不会重复播放，拒绝或断线时停止尚未播完的预览。刀风不代表命中，伤害和掉落仍由服务器确认。
- 其余音效来自服务器确认的瞬时动作事件。失败的进食、急救、建筑放置、空枪或射速冷却不发声，保存失败回滚不播放成功音效。
- 受击声从统一伤害结算入口发布；自然降温和饥饿消耗不播放，子弹被树、箱子或机器挡住或未命中不播放。霰弹枪同一次射击命中同一玩家时只结算一次伤害，也只播放一次受击声。
- 挥斧和怪物近战攻击声只由有效攻击发布；超距、被墙遮挡、冷却中的点击不发声。霰弹枪同一次射击命中同一怪物时，多个弹丸正常造成伤害，但只播放一次命中声、结算一次击退；致死命中仍可同时有命中声与死亡声，死亡声只播放一次。
- 有效拆除持续期间每 0.3 秒最多播放一次砍击声，松开后停止；拆完才播放碎裂声。箱子未清空、建筑正被怪物拆除等无效操作不发声；怪物拆墙也有砍击与碎裂声，但不掉材料。
- 附近角色的声音按距离衰减，18 格以外不播放；最大同时播放 24 个音效，避免过度叠加。
- 初次登录、重连和恢复前台不会补播历史声音，同一事件在多份快照里出现时只播一次。

`cold_world_game/static/js/audio.js` 负责本地资源加载、浏览器声音解锁、去重、衰减和静音。`world.py` 暂存待提交事件，在对应事务成功后发布；这些事件不写入 SQLite 存档。事件字段见 [接口协议](protocol.md) 的“瞬时动作反馈”。
